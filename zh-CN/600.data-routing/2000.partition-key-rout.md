# ODP 支持路由的分区键类型

本文介绍 ODP 支持路由的分区类型和分区键类型。

## 分区

OceanBase 数据库可以把普通的表的数据按照一定的规则划分到不同的区块内，同一区块的数据物理上存储在一起。这种划分区块的表叫做分区表，其中的每一个区块称作分区。OceanBase 数据库支持的分区类型可参见官网《OceanBase 数据库》文档 [分区概述（MySQL）](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000001431048) 和 [分区概述（Oracle）](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000001430973)。

目前 ODP 中支持路由的分区类型如下：

* Range 分区
  
  <main id="notice" type='explain'>
    <h4>说明</h4>
    <p>创建表时，Range 分区类型不支持通过函数（例如 <code>to_days</code>）指定范围，会导致路由不准。</p>
  </main>

* Key 分区

* List 分区

* Hash 分区

* 组合分区

## 分区键

分区键是一个或多个列的集合，用于确定分区表中的每一行所在的分区。每一行都明确地分配给一个分区。OceanBase 数据库使用分区键自动将插入、更新和删除操作定向到相应的分区。

目前 ODP 支持的分区键数据类型如下：

* 时间类型（TIMESTAMP、DATE、DATETIME）

* DOUBLE

  <main id="notice" type='explain'>
    <h4>说明</h4>
    <p>创建列/表时，不支持定义 <code>DOUBLE[(M,D)]</code> 控制精度，可能导致路由不准。</p>
  </main>

* FLOAT

* INT（包含 INT8～INT64）

* DECIMAL

* 字符类型（CHAR、VARCHAR）

* 分区键值为十六进制（格式为 `x'<NUMBER_STR>'  / 0x<NUMBER_STR>  / X'<NUMBER_STR>'  / 0X<NUMBER_STR>`）
