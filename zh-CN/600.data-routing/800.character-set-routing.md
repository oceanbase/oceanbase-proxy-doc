# 字符集路由

ODP 进行分区表的分区键计算时，对于各种类型的分区键，会保证路由准确。目前适配 OceanBase 数据库支持的字符集，进行字符集间转换，再分区计算，达到路由对应分区的效果。字符集转换过程主要分为如下两步：

1. 将原字符集字节串转为 unicode 编码。

2. 将 unicode 编码转换为目标字符集。

目前 ODP 支持如下字符集的分区计算：

* binary

* gbk

* gb18030_2022

* gb18030

* utf16

* utf8mb4

* latin1

* ascii

* tis620

* ujis

* euckr

* cp932

* eucjpms
