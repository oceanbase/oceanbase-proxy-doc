# 日期计算操作

本文介绍日期计算操作相关函数的使用方法。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <ul>
  <li><p>函数中的当前时间是基于 ODP 计算的，和 OBServer 节点的计算会存在偏差。使用 hash 分区且包含当前时间计算的场景下，无法准确路由。</p></li>
  <li><p>自 ODP V4.3.3 起，支持对使用 TIMESTAMP 格式定义的分区键进行路由解析。</p></li>
  </ul>
</main>

## Oracle/MySQL 函数

MySQL 中和日期计算相关的函数包含 CURDATE/CURRENT_DATE、CURTIME/CURRENT_TIME 和 CURRENT_TIMESTAMP/NOW。

Oracle 中和日期计算相关的函数包含 CURRENT_DATE、CURRENT_TIMESTAMP、SYSTIMESTAMP 和 SYSDATE。

<main id="notice" type='explain'>
   <h4>说明</h4>
   <ul>
   <li>
   <p>Oracle 函数后不允许加括号，而 MySQL 函数后允许加括号。</p>
   </li>
   <li>
   <p>Oracle 模式下，不支持 <code>CURRENT_TIMESTAMP(precision)</code> 用法。</p>
   </li>
   </ul>
</main>

此处假设数据库中存在表 `t1`，`c1` 列为分区键。从表 `t1` 中选取所有 `c1` 列值等于当前系统日期按照 `YYYY/MM/DD` 格式转换后的字符串的行，ODP 可以将该 SQL 请求准确路由。示例如下：

```shell
select * from t1 where c1=to_char(sysdate,'YYYY/MM/DD');
```

## MONTH

MONTH 函数的作用是从给定的日期中提取月份，目前仅支持 MONTH(date) 用法。

* 示例一：分区表达式中使用
  
  创建 `orders` 表，并指定按照订单月份进行分区。

  ```sql
  CREATE TABLE orders (
      order_id INT,
      order_date DATE,
      amount DECIMAL(10,2)
  )
  PARTITION BY RANGE (MONTH(order_date)) (
      PARTITION p1 VALUES LESS THAN (2),   -- 1月
      PARTITION p2 VALUES LESS THAN (3),   -- 2月
      PARTITION p3 VALUES LESS THAN (4),   -- 3月
      ...
      PARTITION p12 VALUES LESS THAN (13)  -- 12月
  );
  ```

* 示例二：分区键中使用
  
  假设数据库中存在表 `t1`，`c1` 列为分区键。查询 `t1` 表中所有 `c1` 列值与日期 `2025-05-20` 中月份值相等的行，ODP 可以将该 SQL 请求准确路由。

  ```shell
  select * from t1 where c1=MONTH('2025-05-20');
  ```

## TO_DATE

TO_DATE 函数的作用是将字符串转换为日期或日期时间类型数据。目前仅支持 to_date(char,[fmt]) 用法：

* `char` 为待转换的字符串，表示一个具体的日期和时间。

* `fmt` 为可选值，用于设置转换格式。

此处假设数据库中存在表 `t1`，`c1` 列为分区键。查询 `t1` 表中所有 `c1` 列值与字符串 `20230823024916` 按照指定格式转换后的日期时间相等的行，ODP 可以将该 SQL 请求准确路由。示例如下：

```shell
select * from t1 where c1=TO_DATE('20230823024916','YYYYMMDDHH24MISS');
```

## TO_DAYS

TO_DAYS 函数的作用是将给定的日期转换为自公元 0 年以来的天数（整数）。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该函数返回的天数是距离 <code>0000-01-01</code> 的天数。</p>
</main>

ODP 支持分区键中携带 TO_DAYS 函数，ODP 会将其转为对应的天数，实现携带此函数的 SQL 准确路由。

此处假设数据库中存在表 `t1`，`c1` 列为分区键。查询 `t1` 表中所有 `c1` 列值与 `2015-11-04` 距 `0000-01-01` 的天数值相同的行。示例如下：

```shell
select * from t1 where c1=TO_DAYS('2015-11-04');
```

## TO_TIMESTAMP

TO_TIMESTAMP 函数的作用是将字符串转换为 timestamp 类型的日期时间数据。目前仅支持 to_timestamp(str, [fmt]) 用法：

* `str` 为待转换的字符串，表示一个具体的日期和时间。

* `fmt` 为可选值，用于设置转换格式。

此处假设数据库中存在表 `t1`，`c1` 列为分区键。查询 `t1` 表中所有 `c1` 列值与字符串 `20230823191416` 按照指定格式转换后的 timestamp 类型时间戳相等的行，ODP 可以将该 SQL 请求准确路由。示例如下：

```shell
select * from t1 where c1=to_timestamp('20230823191416','YYYY-MM-DD HH24:MI:SSXFF');
```
