# init_sql

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.2.1 版本开始引入。</p>
</main>

## 功能描述

`init_sql` 用于设置 ODP 在连接 OceanBase 集群成功后发送给 OceanBase 集群的初始化 SQL。

## 属性说明

|  属性    | 描述     |
|----------|---------|
| 参数类型 | 字符串类型      |
| 默认值   | 不涉及     |
| 取值范围 | 不涉及   |
| 是否重启 ODP 生效 | 否  |

## 配置示例

执行如下命令，设置 ODP 在连接 OceanBase 集群成功后，初始化 `_show_ddl_in_compat_mode` 为 `1`。

```shell
obclient> ALTER proxyconfig SET init_sql='set _show_ddl_in_compat_mode = 1;';
```
