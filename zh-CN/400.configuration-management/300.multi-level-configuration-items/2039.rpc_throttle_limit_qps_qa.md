# rpc_throttle_limit_qps_qa

`rpc_throttle_limit_qps_qa` 用于设置触发限流时 RPC 请求的 QPS 限制。

|  属性    | 描述     |
|----------|---------|
| 参数类型 | 整数类型        |
| 默认值   | 0，表示为当前 QPS 的 70%    |
| 取值范围 | [0, +∞)  |
| 是否重启 ODP 生效 | 否  |

## 使用示例

设置触发限流时 RPC 请求的 QPS 限制为 500：

```shell
obclient> alter proxyconfig set rpc_throttle_limit_qps_qa= 500;
```
