# rpc_throttle_trigger_percentage

`rpc_throttle_trigger_percentage` 用于设置限流触发阈值，当 RPC 请求占用内存达到设置的百分比后开始限流。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.2 版本开始引入。</p>
</main>

|  属性    | 描述     |
|----------|---------|
| 参数类型 | 整数类型        |
| 默认值   | 50    |
| 取值范围 | [0, 100)  |
| 是否重启 ODP 生效 | 否  |

## 使用示例

设置当 RPC 请求占用内存 40% 时开始限流：

```shell
obclient> alter proxyconfig set rpc_throttle_trigger_percentage= 40;
```
