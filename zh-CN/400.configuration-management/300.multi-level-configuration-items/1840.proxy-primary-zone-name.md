# proxy_primary_zone_name

`proxy_primary_zone_name` 用于设置 ODP LDC 路由的主可用区（Primary Zone）名称。如果不为空，则 ODP 仅路由到该区域。

该配置项支持配置多个 Zone 名称，多个 Zone 名称需要使用英文分号（`;`）或英文逗号（`,`）进行分割，不同的分隔符代表了不同的路由优先级，具体如下：

* 分号（`;`）表示不同的 Zone 具有从高到底的优先级，即 `;` 前的 Zone 路由优先级高于 `;` 后的 Zone。

* 逗号（`,`）表示不同的 Zone 具有相同优先级，即以 `,` 分隔的 Zone 优先级相同，ODP 将会随机路由到配置的任意的 Zone。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <ul>
  <li>
  <p>该配置项自 ODP V4.3.1 起支持配置多个 Zone，V4.3.1 之前版本仅支持配置一个 Zone 名称。</p>
  </li>
  <li>
  <p>配置时要求 Zone 名称中不带有 <code>;</code> 或 <code>,</code>，否则会被解析为分隔符进行分割。</p>
  </li>
  </ul>
</main>

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   字符串类型      |
| 默认值   | 空字符串     |
| 取值范围 | 不涉及  |
| 是否重启 ODP 生效 | 否  |

## 示例

假设集群中存在 z1~z6 六个 Zone，此处以配置 ODP 的优先级为 z1 = z2 > z3 = z4 > z5 = z6 为例：

```shell
alter proxyconfig set proxy_primary_zone_name='z1,z2;z3,z4;z5,z6'
```
