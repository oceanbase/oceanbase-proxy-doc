# rpc_request_throttle_waiting_time

`rpc_request_throttle_waiting_time` 用于设置 RPC 请求限流等待时间。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.2 版本开始引入。</p>
</main>

|  属性    | 描述     |
|----------|---------|
| 参数类型 | 时间类型        |
| 默认值   | 1ms    |
| 取值范围 | [0ms, 10s]  |
| 是否重启 ODP 生效 | 否  |

## 使用示例

设置 RPC 请求限流等待时间为 10ms：

```shell
obclient> alter proxyconfig set rpc_request_throttle_waiting_time= 10ms;
```
