# route_diagnosis_level

`route_diagnosis_level` 用于控制诊断日志（`obproxy_diagnosis.log`）中路由诊断信息的详细程度，配置的值越大，展示的状态信息越详细。配置值为 `0` 时表示关闭该模块，关闭该模块时，不会占用 ODP 内存，也不会影响 ODP 性能。

|  属性    | 描述     |
|----------|---------|
| 参数类型 | 整数类型        |
| 默认值   | 2    |
| 取值范围 | [0, 4]  |
| 是否重启 ODP 生效 | 否  |
