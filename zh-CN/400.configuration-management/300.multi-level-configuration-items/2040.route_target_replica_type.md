# route_target_replica_type

`route_target_replica_type` 用于指定副本类型，在 `proxy_route_policy` 配置为指定副本路由类型（`TARGET_REPLICA_TYPE_` 开头的路由策略）时，此配置才生效。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.2 版本开始引入。</p>
</main>

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   字符串类型      |
| 默认值   | 空字符串     |
| 取值范围 | <ul><li>Full：仅路由到备副本</li><li>Readonly：进路由到只读副本</li><li>ColumnStore：仅路由到列存副本</li><li>Full;Readonly：路由到备副本和只读副本</li></ul><main id="notice" type='explain'><h4>说明</h4><p>当 <code>proxy_route_policy</code> 配置为以 <code>TARGET_REPLICA_TYPE_</code> 开头的路由策略时，若 <code>route_target_replica_type</code> 配置为 <code>ColumnStore</code>，只会路由到列存副本。</p></main> |
| 是否重启 ODP 生效 | 否  |
<!-- 了解是否重启生效、默认值 -->
