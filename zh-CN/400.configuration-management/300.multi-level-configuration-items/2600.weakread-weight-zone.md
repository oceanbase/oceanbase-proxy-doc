# weakread_weight_zone

`weakread_weight_zone` 用于配置各个 Zone 的权重，仅在 `proxy_route_policy` 指定为权重负载均衡路由策略（`WEAKREAD_WEIGHT_LOAD_BALANCE`）时生效。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <ul>
  <li>
  <p>该配置项自 4.3.2 版本开始引入。</p>
  </li>
  <li>
  <p>仅支持配置为租户级别或 VIP 级别，且不能配置为空字符，否则会拦截报错。</p>
  </li>
  </ul>
</main>

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   字符串类型      |
| 默认值   | ""，表示空字符串     |
| 取值范围 | 默认情况下所有 Zone 的权重相同，设置权重时需按照 `zone_name:num` 格式配置，`zone_name` 表示待配置的 Zone 的名字，不允许重复，但可以设置不存在的 Zone，此时该 Zone 不参与权重计算；`num` 表示各个 Zone 的权重，可取值为 [0, 100] 范围内的整数。多个 Zone 之间使用英文分号（`;`）隔开。 |
| 是否重启 ODP 生效 | 否  |
