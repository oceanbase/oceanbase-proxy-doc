# enable_standby_read_write_split

`enable_standby_read_write_split` 用于控制通过 Service Name 登录的租户是否开启租户间读写分离功能。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <ul>
  <li><p>该配置项自 4.3.3 版本开始引入。</p></li>
  <li><p>配置修改仅对新建连接生效，对已存在的连接不生效。</p></li>
  </ul>
</main>

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   布尔类型      |
| 默认值   | False     |
| 取值范围 | <ul><li>True：开启租户间读写分离功能</li><li>False：关闭租户间读写分离功能</li></ul>  |
| 是否重启 ODP 生效 | 否  |

## 示例

配置租户级别时，租户名格式为 `service:xxxx`，集群名为空。此处以开启 `service_nameA` 的主备租户读写分离能力为例，示例如下：

```sql
replace into proxy_config(cluster_name, tenant_name, name, value, config_level) values ('', 'service:service_nameA', 'enable_standby_read_write_split', 'true', 'LEVEL_TENANT');
```
