# enable_standby_read_write_split

`enable_standby_read_write_split` 用于控制通过 Service Name 登录的租户是否开启主备租户读写分离功能。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <ul>
  <li><p>该配置项自 4.3.3 版本开始引入。</p></li>
  <li><p>配置修改仅对新建连接生效，对已存在的连接不生效。</p></li>
  </ul>
</main>

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   布尔类型      |
| 默认值   | False     |
| 取值范围 | <ul><li>True：开启主备租户读写分离功能</li><li>False：关闭主备租户读写分离功能</li></ul>  |
| 是否重启 ODP 生效 | 否  |

## 示例

配置租户级别时，租户名格式为 `service:xxxx`，集群名为空。此处以开启 `service_name_a` 的主备租户读写分离能力为例，示例如下：

1. 设置 `service_name_a` 的备集群为 `cluster_A`

   ```sql
   replace into proxy_config(cluster_name, tenant_name, name, value, config_level) values ('', 'service:service_name_a', 'rootservice_cluster_name', 'cluster_A', 'LEVEL_TENANT');
   ```

   通过 Service Name 登录时，`rootservice_cluster_name` 配置项用于设置读写分离场景下优先路由的备集群。未配置 `rootservice_cluster_name` 的场景下，开启主备租户读写分离能力后，ODP 默认会将需要发给备租户的请求优先发给缓存中的第一个备租户。

2. 开启 `service_name_a` 的主备租户读写分离能力

   ```sql
   replace into proxy_config(cluster_name, tenant_name, name, value, config_level) values ('', 'service:service_name_a', 'enable_standby_read_write_split', 'true', 'LEVEL_TENANT');
   ```
