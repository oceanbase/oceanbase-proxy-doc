# binlog_service_ip

`binlog_service_ip` 用于设置 binlog 服务集群地址。支持配置为 IP 地址或域名，多个 IP 或域名间以英文分号（`;`）分割，例如 `域名1:PORT1;IP2:PORT2;域名3:PORT3;IP4:PORT4`。配置成功后优先使用排列在前的地址。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.1 版本起支持配置多个 IP 地址或域名。</p>
</main>

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   字符串类型      |
| 默认值   | 空字符串     |
| 取值范围 | 不涉及  |
| 是否重启 ODP 生效 | 否  |
