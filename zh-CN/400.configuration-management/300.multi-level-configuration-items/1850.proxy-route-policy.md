# proxy_route_policy

`proxy_route_policy` 用于设置 ODP 弱读请求路由策略，控制客户端请求被路由到哪个后端服务器上进行处理。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <ul>
  <li><p>该配置项自 4.3.2 版本起取值中新增 <code>TARGET_REPLICA_TYPE_WITH_LEADER</code>、<code>TARGET_REPLICA_TYPE_FOLLOWER_FIRST</code>、<code>TARGET_REPLICA_TYPE_FOLLOWER_ONLY</code> 和 <code>WEAKREAD_WEIGHT_LOAD_BALANCE</code>。</p></li>
  <li><p>该配置项的取值不区分大小写。</p></li>
  <li><p>若配置的值非下文取值范围中的值，可以配置成功，但不会生效，ODP 将按照默认路由策略进行路由。</p></li>
  </ul>
</main>

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   字符串类型      |
| 默认值   | ''，表示空字符串     |
| 取值范围 | <ul><li>空字符串：表示使用 ODP 默认的路由策略（`MERGE_IDC_ORDER`），弱读时允许请求被路由到备副本和只读副本。</li><li><code>FOLLOWER_FIRST</code>：优先选择备副本，如果备副本都不可用，选择主副本。</li><li><code>FOLLOWER_ONLY</code>：选择备副本，如果备副本都不可用，断开和客户端的连接。</li><li><code>UNMERGE_FOLLOWER_FIRST</code>：优先选择不在集群合并状态的备副本。</li><li><code>TARGET_REPLICA_TYPE_WITH_LEADER</code>：指定副本路由，主副本与备副本优先级相同。备副本的类型由 <code>route_target_replica_type</code> 决定。</li><li><code>TARGET_REPLICA_TYPE_FOLLOWER_FIRST</code>：指定副本路由，优先选择备副本，当所有备副本不可用时会选择主副本。备副本的类型由 <code>route_target_replica_type</code> 决定。</li><li><code>TARGET_REPLICA_TYPE_FOLLOWER_ONLY</code>：指定副本路由，只会选择备副本，当备副本都不可用时，断开和客户端的连接。备副本的类型由 <code>route_target_replica_type</code> 决定。</li><li><code>WEAKREAD_WEIGHT_LOAD_BALANCE</code>：基于权重进行负载均衡路由，可通过配置 <code>weakread_weight_zone</code> 为集群中的各个 Zone 设置权重。</li></ul>  |
| 是否重启 ODP 生效 | 否  |

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>当 <code>route_target_replica_type</code> 配置为 <code>ColumnStore</code> 时，ODP 只会将请求路由到列存副本，不会路由到主副本。</p>
</main>
