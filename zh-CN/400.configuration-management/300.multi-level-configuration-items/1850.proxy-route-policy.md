# proxy_route_policy

`proxy_route_policy` 用于设置 ODP 弱读请求路由策略，控制客户端请求被路由到哪个后端服务器上进行处理。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <ul>
  <li><p>该配置项自 4.3.2 版本起取值中新增 <code>TARGET_REPLICA_TYPE_WITH_LEADER</code>、<code>TARGET_REPLICA_TYPE_FOLLOWER_FIRST</code>、<code>TARGET_REPLICA_TYPE_FOLLOWER_ONLY</code> 和 <code>WEAKREAD_WEIGHT_LOAD_BALANCE</code>。</p></li>
  <li><p>该配置项的取值不区分大小写。</p></li>
  </ul>
</main>
|  属性    | 描述     |
|----------|---------|
| 参数类型 |   字符串类型      |
| 默认值   | 空字符串     |
| 取值范围 | <ul><li>FOLLOWER_FIRST：优先选择备副本，如果备副本都不可用，选择主副本</li><li>FOLLOWER_ONLY：选择备副本，如果备副本都不可用，断开和客户端的连接</li><li>UNMERGE_FOLLOWER_FIRST：优先选择不在集群合并状态的备副本</li><li>TARGET_REPLICA_TYPE_WITH_LEADER：指定副本路由时优先选择主副本，备副本优先级由 <code>route_target_replica_type</code> 决定，未配置 <code>route_target_replica_type</code> 时备副本优先级相同</li><li>TARGET_REPLICA_TYPE_FOLLOWER_FIRST：会选LEADER，但FOLLOWER优先级更高</li><li>TARGET_REPLICA_TYPE_FOLLOWER_ONLY：不会路由到主副本</li><li>WEAKREAD_WEIGHT_LOAD_BALANCE：选择权重负载均衡路由策略</li></ul>  |
| 是否重启 ODP 生效 | 否  |

<!-- 说明默认值空字符串的含义 -->

<!-- TARGET_REPLICA_TYPE_WITH_LEADER：优先选择主副本，备副本优先级相同--是说 主副本不可用时选择备副本 么 -->
<!-- TARGET_REPLICA_TYPE_FOLLOWER_FIRST：会选LEADER，但FOLLOWER优先级更高---备副本优先级更高，那为什么会路由到主副本么，这个配置的使用场景是什么呀 -->
<!-- TARGET_REPLICA_TYPE_FOLLOWER_ONLY：不会路由到主副本---这个和 FOLLOWER_ONLY 含义一样么，即 选择备副本，如果备副本都不可用，断开和客户端的连接 -->
