# enable_check_cluster_name

`enable_check_cluster_name` 用于控制三段式登录时是否校验集群名。配置为 `True` 时，会校验集群名是否等于默认集群名（由 `rootservice_cluster_name` 配置），校验失败将拒绝登录。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <ul>
  <li><p>该配置项自 4.3.3 版本开始引入。</p></li>
  <li><p>三段式登录表示通过配置用户名、租户名、集群名的方式登录，如 <code>root@sys#obdemo</code>。</p></li>
  </ul>
</main>

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   布尔类型      |
| 默认值   | False     |
| 取值范围 | <ul><li>True：校验集群名</li><li>False：不校验集群名</li></ul>  |
| 是否重启 ODP 生效 | 否  |

## 示例

此处假设 `obdemo` 集群中存在 `test1`、`test2` 租户，以设置登录 `test1` 租户时校验集群名，登录 `test2` 租户时不校验集群名为例，示例如下：

```shell
obclient [(none)]> replace into proxy_config(tenant_name, cluster_name, name, value, config_level) values 
    ('test1','obdemo','enable_check_cluster_name','True','LEVEL_TENANT'),
    ('test2','obdemo','enable_check_cluster_name','False','LEVEL_TENANT');
```
