# rootservice_cluster_name

根据登录方式的不同，`rootservice_cluster_name` 配置项有如下几种作用：

* 通过 Service Name 登录时，该配置项表示读写分离下的默认备集群。

* 非 Service Name 登录时，该配置项用于设置 `rootservice_list` 的默认集群名，或云用户的默认集群名。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 ODP 4.3.3 版本起更新，区分是否通过 Service Name 登录，通过 Service Name 登陆时，该配置项表示读写分离下的默认备集群。</p>
</main>

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   字符串类型      |
| 默认值   | undefined     |
| 取值范围 | 不涉及  |
| 是否重启 ODP 生效 | 是  |
