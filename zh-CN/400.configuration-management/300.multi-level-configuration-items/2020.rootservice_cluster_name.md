# rootservice_cluster_name

`rootservice_cluster_name` 用于设置 `rootservice_list` 的默认集群名，或云用户的默认集群名。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.3 版本起更新，新增了设置云用户默认集群名的功能。</p>
</main>

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   字符串类型      |
| 默认值   | undefined     |
| 取值范围 | 不涉及  |
| 是否重启 ODP 生效 | 是  |

rootservice_list 的详细介绍可参见 [rootservice_list](../200.global-configuration-items/2030.rootservice_list.md)。
