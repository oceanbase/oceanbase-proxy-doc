# enable_rpc_throttle

`enable_rpc_throttle` 用于控制是否基于 RPC 请求占用内存的情况进行流量控制。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.2 版本开始引入。</p>
</main>

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   布尔类型      |
| 默认值   | False     |
| 取值范围 | <ul><li>True：开启流量控制</li><li>False：关闭流量控制</li></ul>  |
| 是否重启 ODP 生效 | 否  |

## 使用示例

```shell
obclient> alter proxyconfig set enable_rpc_throttle=true;
```
