# enable_syslog_file_compress

`enable_syslog_file_compress` 用于控制是否开启归档日志压缩。

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   布尔类型      |
| 默认值   | False     |
| 取值范围 | <ul><li>True：开启存档日志压缩</li><li>False：不开启存档日志压缩</li></ul>  |
