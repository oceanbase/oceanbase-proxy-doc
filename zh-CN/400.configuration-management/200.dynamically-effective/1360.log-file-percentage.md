# log_file_percentage

`log_file_percentage` 用于设置 ODP 日志文件占用可用空间的百分比阈值。日志占用空间超过 `min(log_dir_size_threshold, 日志文件夹可用空间*log_file_percentage)` 值后进行日志清理，取值为 `0` 时表示忽略此限制。

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   整数类型      |
| 默认值   | 80     |
| 取值范围 | [0, 100]  |

`log_dir_size_threshold` 配置项的详细介绍可参见 [log_dir_size_threshold](1350.log-dir-size-threshold.md)。

## 示例

此处以日志文件夹的可用空间为 80G、`log_dir_size_threshold` 设置为 64G 为例。

* 执行如下命令设置 ODP 日志文件占可用空间的 90%

  ```sql
  alter proxyconfig set log_file_percentage=90%;
  ```

  成功设置后，按照计算规则，ODP 日志文件最大可占用空间大小为 min(64G, 80G*90%)=64G。

* 执行如下命令设置 ODP 日志文件占可用空间的 70%

  ```sql
  alter proxyconfig set log_file_percentage=70%;
  ```

  成功设置后，按照计算规则，ODP 日志文件最大可占用空间大小为 min(64G, 80G*70%)=56G。
