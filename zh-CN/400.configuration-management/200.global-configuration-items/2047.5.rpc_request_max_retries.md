# rpc_request_max_retries

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.0 版本开始引入，并于 4.3.4 版本废弃。您可以查询并修改该配置项，但是该配置项并不会生效。</p>
</main>

## 功能描述

`rpc_request_max_retries` 用于设置 RPC 请求在错误分区查找失败时的重试次数。

## 属性说明

|  属性    | 描述     |
|----------|---------|
| 参数类型 | 整数类型      |
| 默认值   | 300     |
| 取值范围 | [1, +∞)  |
| 是否重启 ODP 生效 | 否  |

## 配置示例

执行如下命令，设置 RPC 请求在错误分区查找失败时重试 400 次。

```shell
obclient> alter proxyconfig set rpc_request_max_retries= 400;
```
