# rpc_sub_request_weight

`rpc_sub_request_weight` 用于设置 RPC 子请求的权重，子请求占用普通线程的数量随着权重的增高而增多。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <ul>
  <li><p>该配置项自 4.3.2 版本开始引入。</p></li>
  <li><p>该配置项仅在 <a href="2052.5.rpc_sub_request_isolation_mode.md">rpc_sub_request_isolation_mode</a> 配置为 <code>2</code> 时生效。</p></li>
  </ul>
</main>

|       属性        |   描述   |
| ----------------- | -------- |
| 参数类型          | 整数类型  |
| 默认值            | 10       |
| 取值范围          | [0, +∞)  |
| 是否重启 ODP 生效 | 否       |
