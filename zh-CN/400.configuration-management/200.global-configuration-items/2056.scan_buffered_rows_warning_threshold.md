# scan_buffered_rows_warning_threshold

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.2.3 版本开始引入。</p>
</main>

## 功能描述

`scan_buffered_rows_warning_threshold` 用于设置分片表扫描请求获取的行数阈值，超过阈值时将在 ODP 日志中打印警告信息。

## 属性说明

|  属性    | 描述     |
|----------|---------|
| 参数类型 | 整数类型      |
| 默认值   | 50000     |
| 取值范围 | [-1, +∞)  |
| 是否重启 ODP 生效 | 否  |

## 配置示例

执行如下命令，设置分片表扫描请求最多能获取的行数为 60000 行。

```shell
obclient> alter proxyconfig set scan_buffered_rows_warning_threshold= 60000;
```
