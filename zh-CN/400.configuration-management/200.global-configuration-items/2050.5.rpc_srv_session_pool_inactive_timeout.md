# rpc_srv_session_pool_inactive_timeout

`rpc_srv_session_pool_inactive_timeout` 配置项用于设置同步模块中服务端连接的 inactive 过期时间。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.0 版本开始引入。</p>
</main>

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   时间类型      |
| 默认值   | 30s     |
| 取值范围 | [0s, 1d]  |
| 是否重启 ODP 生效 | 否  |
