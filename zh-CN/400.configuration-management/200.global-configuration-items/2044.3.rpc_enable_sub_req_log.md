# rpc_enable_sub_req_log

`rpc_enable_sub_req_log` 配置项用于控制是否在 obproxy_slow.log 和 obproxy_digest.log 日志中打印满足打印条件的 OBKV 子请求日志。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <ul>
  <li><p>对于 ODP V4.3.1.x 系列版本，该配置项自 4.3.1 BP7 版本开始引入。</p></li>
  <li><p>该配置项对 SQL 业务无影响。</p></li>
  </ul>
</main>

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   布尔类型      |
| 默认值   | True     |
| 取值范围 | <ul><li>True：打印满足打印条件的 OBKV 子请求日志。</li><li>False：不打印满足打印条件的 OBKV 子请求日志。</li></ul>  |
| 是否重启 ODP 生效 | 否  |

## 示例

开启子请求日志打印后如果性能下降过多，影响业务，可执行如下命令将其置为 False 关闭。

```sql
obclient> alter proxyconfig set rpc_enable_sub_req_log='False';
```

## 相关文档

* 需配置 `enable_trace` 为 `True` 开启追踪日志打印功能，才会打印满足打印条件的 OBKV 子请求日志。enable_trace 配置项的具体介绍可参见 [enable_trace](910.enable-trace.md)。

* slow 日志打印时间阈值由 `slow_query_time_threshold` 配置项控制，超过阈值的子请求才会打印到 `obproxy_slow.log`。`slow_query_time_threshold` 配置项的具体介绍可参见 [slow_query_time_threshold](../300.multi-level-configuration-items/2350.slow-query-time-threshold.md)。

* digest 日志打印时间阈值由 `query_digest_time_threshold` 配置项控制，超过阈值的子请求才会打印到 `obproxy_digest.log`。`query_digest_time_threshold` 配置项的具体介绍可参见 [query_digest_time_threshold](../300.multi-level-configuration-items/1930.query-digest-time-threshold.md)。
