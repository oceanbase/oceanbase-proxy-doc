# server_protocol

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.4 版本开始引入。</p>
</main>

## 功能描述

`server_protocol` 用于控制 ODP 与 OceanBase 数据库之间的协议类型。

## 属性说明

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   字符串类型      |
| 默认值   | Auto    |
| 取值范围 | 可配置为 `Auto`、`MySQL`、`Compressed MySQL`、`OceanBase 2.0`，不区分大小写。不同取值的具体含义如下：<ul><li><code>Auto</code>：当 <code>enable_single_leader_node_routing</code> 配置为 <code>True</code> 时，在租户 Leader 副本聚集的场景下，对应租户的连接使用 MySQL 协议，其他场景使用 OceanBase 2.0 协议。当 <code>enable_single_leader_node_routing</code> 配置为 <code>False</code> 时，所有租户均使用 OceanBase 2.0 协议。</li><li><code>MySQL</code>：强制使用 MySQL 协议。</li><li><code>Compressed MySQL</code>：强制使用压缩协议，不建议配置为该值，OceanBase 2.0 协议也具有压缩数据功能，有压缩数据需求时直接使用 OceanBase 2.0 协议即可。</li><li><code>OceanBase 2.0</code>：强制使用 OceanBase 2.0 协议。</li></ul>  |
| 是否重启 ODP 生效 | 否，重建连接即生效  |

## 配置示例

设置 ODP 与 OceanBase 数据库之间强制使用 MySQL 协议。

```sql
obclient> alter proxyconfig set server_protocol='MySQL';
```
