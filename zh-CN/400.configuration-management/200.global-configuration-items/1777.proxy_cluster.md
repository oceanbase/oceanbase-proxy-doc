# proxy_cluster

  <h4>说明</h4>

## 功能描述

`proxy_cluster` 用于设置 ODP 集群名称，标记该 ODP 所属的 ODP 集群。

## 属性说明

|  属性    | 描述     |
|----------|---------|
| 参数类型 | 字符串类型      |
| 默认值   | undefined     |
| 取值范围 | 不涉及  |
| 是否重启 ODP 生效 | 否  |

## 配置示例

执行如下命令，设置 ODP 所属的 ODP 集群为 `test`。

```shell
obclient> alter proxyconfig set proxy_cluster='test';
```
