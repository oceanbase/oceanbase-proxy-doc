# rpc_enable_async_analyze

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.2 版本开始引入。</p>
</main>

## 功能描述

`rpc_enable_async_analyze` 用于控制 RPC 是否异步解析大的请求或者结果集。

## 属性说明

|  属性    | 描述     |
|----------|---------|
| 参数类型 | 布尔类型      |
| 默认值   | False     |
| 取值范围 | <ul><li>True：异步解析大的请求或者结果集。</li><li>False：不异步解析大的请求或者结果集。</li></ul>  |
| 是否重启 ODP 生效 | 否  |

## 配置示例

执行如下命令，设置启用异步解析大的请求或者结果集。

```shell
obclient> alter proxyconfig set rpc_enable_async_analyze='True';
```
