# rpc_enable_async_analyze

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.2 版本开始引入。</p>
</main>

## 功能描述

`rpc_enable_async_analyze` 用于控制是否启用异步分析大包功能。

## 属性说明

|  属性    | 描述     |
|----------|---------|
| 参数类型 | 布尔类型      |
| 默认值   | False     |
| 取值范围 | <ul><li>True：启用异步分析大包功能。</li><li>False：不启用异步分析大包功能。</li></ul>  |
| 是否重启 ODP 生效 | 否  |

## 配置示例

执行如下命令，设置启用异步分析大包功能。

```shell
obclient> alter proxyconfig set rpc_enable_async_analyze='True';
```
