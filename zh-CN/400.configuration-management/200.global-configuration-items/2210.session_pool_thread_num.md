# session_pool_thread_num

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.5 版本开始引入。</p>
</main>

## 功能描述

`session_pool_thread_num` 用于设置处理会话池事件的线程数，线程用于处理由连接池中的会话触发的事件。

## 属性说明

|  属性    | 描述     |
|----------|---------|
| 参数类型 | 整数类型      |
| 默认值   | 1     |
| 取值范围 | [1, 128]  |
| 是否重启 ODP 生效 | 是  |

## 配置示例

执行如下命令，设置处理会话池事件的线程数为 4。

```shell
obclient> alter proxyconfig set session_pool_thread_num= 4;
```
