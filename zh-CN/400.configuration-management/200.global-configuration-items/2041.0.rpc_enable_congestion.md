# rpc_enable_congestion

`rpc_enable_congestion` 配置项用于控制 RPC 请求是否开启 Server 黑名单处理过程。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.0 版本开始引入。</p>
</main>

| 参数类型 |   布尔类型      |
| 默认值   | False     |
| 取值范围 | <ul><li>True：开启 Server 黑名单处理过程。</li><li>False：不开启 Server 黑名单处理过程。</li></ul>  |
| 是否重启 ODP 生效 | 否  |
