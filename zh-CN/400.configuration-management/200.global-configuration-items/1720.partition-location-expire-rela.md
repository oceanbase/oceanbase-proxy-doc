# partition_location_expire_relative_time

`partition_location_expire_relative_time` 用于设置 ODP 中缓存过期时间，单位为毫秒，设置为 `0` 时表示不过期，设置为其他数值时，ODP 将根据相对时间过期缓存。

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   整数类型      |
| 默认值   | 0     |
| 取值范围 | [-36000000,36000000]  |
| 是否重启 ODP 生效 | 否  |
