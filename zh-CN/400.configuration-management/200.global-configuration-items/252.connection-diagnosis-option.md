# connection_diagnosis_option

`connection_diagnosis_option` 通过 bit 位指定当前连接诊断的能力。

* 比特 0：用于指定是否开启连接诊断日志记录。

* 比特 1：用于指定是否在内部错误发生时尝试构建错误包。

* 比特 2：用于指定是否打印正常登录或登出日志。

<main id="notice" type='explain'>
   <h4>说明</h4>
   <ul>
   <li><p>该配置项自 4.2.2 版本开始引入，并于 4.2.3 版本起默认值由 <code>1</code> 更新为 <code>3</code>。</p></li>
   <li><p>自 4.3.6 版本新增第三个 bit 位表示是否打印正常登录或登出日志，并将默认值由 <code>3</code> 更新为 <code>7</code>。</p></li>
   </ul>
</main>

|  属性    | 描述     |
|----------|---------|
| 参数类型 | 整数类型   |
| 默认值   | 7     |
| 取值范围 | [0, 7]  |
| 是否重启 ODP 生效 | 否  |

当配置项 <code>connection_diagnosis_option</code> 值为 <code>7</code> 时，在短链接场景下，ODP V4.3.6 相较于 V4.3.5，性能最大下降 6%。因此，不同使用场景下，配置项 <code>connection_diagnosis_option</code> 的推荐值不同，具体如下：

* 长连接场景下，登出日志几乎没有太大性能影响，推荐设置配置项 <code>connection_diagnosis_option</code> 值为 <code>7</code>。

* 若对短连接场景性能敏感，推荐设置 <code>connection_diagnosis_option</code> 值为 <code>3</code>、<code>protocol_diagnosis_level</code> 值为 <code>0</code>。

<main id="notice" type='notice'>
   <h4>注意</h4>
   <p>极致性能配置下，可能会出现程序发生异常（例如断连接、hung）时缺少关键诊断日志的情况，建议您酌情考虑。</p>
</main>
