# connection_diagnosis_option

`connection_diagnosis_option` 通过 bit 位指定当前连接诊断的能力。

<main id="notice" type='explain'>
   <h4>说明</h4>
   <ul>
   <li><p>该配置项自 4.2.2 版本开始引入，并于 4.2.3 版本起默认值由 <code>1</code> 更新为 <code>3</code>。</p></li>
   <li><p>自 4.3.6 版本新增第三个 bit 位表示是否打印正常登录或登出日志，并将默认值由 <code>3</code> 更新为 <code>7</code>。</p></li>
   </ul>
</main>

|  属性    | 描述     |
|----------|---------|
| 参数类型 | 整数类型   |
| 默认值   | 7     |
| 取值范围 | [0, 7]  |
| 是否重启 ODP 生效 | 否  |

该配置项用二进制位表示：

* 比特 0：用于指定是否开启连接诊断日志记录。

* 比特 1：用于指定是否在内部错误发生时尝试构建错误包。

* 比特 2：用于指定是否打印正常登录或登出日志。
