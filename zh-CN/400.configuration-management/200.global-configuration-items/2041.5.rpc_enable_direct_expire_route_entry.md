# rpc_enable_direct_expire_route_entry

`rpc_enable_direct_expire_route_entry` 配置项用于控制是否强制失效清理过期的路由信息，不再使用脏数据进行异步刷新。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.0 版本开始引入。</p>
</main>

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   布尔类型      |
| 默认值   | False     |
| 取值范围 | <ul><li>True：强制失效清理过期的路由信息。</li><li>False：不强制失效清理过期的路由信息。</li></ul>  |
| 是否重启 ODP 生效 | 否  |
