# rpc_sub_req_max_retries

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.1 版本开始引入。</p>
</main>

## 功能描述

`rpc_sub_req_max_retries` 用于设置 RPC 子请求在请求失败后的最大重试次数。

## 属性说明

|  属性    | 描述     |
|----------|---------|
| 参数类型 | 整数类型      |
| 默认值   | 5     |
| 取值范围 | [0, 50]  |
| 是否重启 ODP 生效 | 是  |

## 配置示例

执行如下命令，设置 RPC 子请求在请求失败后最多重试 10 次。

```shell
obclient> alter proxyconfig set rpc_sub_req_max_retries= 10;
```
