# is_need_skip_delay_interval_schema_changed

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>ODP V4.3.1 BP4 及之后的 V4.3.1.x 版本，V4.3.4 及之后版本支持使用该配置项。</p>
</main>

## 功能描述

`is_need_skip_delay_interval_schema_changed` 用于控制当表的 schema_version 更改时是否需要跳过延迟间隔。

该配置项主要用于 Range 分区自动分裂场景，例如，若 OceanBase 数据库中表分区间隔 5 秒内发生分裂，ODP 构建新的分区信息后，会强制要求下一次分区信息构建必须等待至少 5 秒后才能触发更新，将会导致 ODP 无法获取准确的分区路由信息。建议配置为 `True`，当分区 schema_version 小于表的 schema_version 时，不受间隔时间影响，直接刷新分区路由。

## 属性说明

|  属性    | 描述     |
|----------|---------|
| 参数类型 | 布尔类型      |
| 默认值   | False     |
| 取值范围 | <ul><li>True：跳过延迟间隔</li><li>False：不跳过延迟间隔</li></ul>  |
| 是否重启 ODP 生效 | 否  |

## 配置示例

执行如下命令，设置当表的 schema_version 更改时跳过延迟间隔。

```shell
obclient> alter proxyconfig set is_need_skip_delay_interval_schema_changed='True';
```
