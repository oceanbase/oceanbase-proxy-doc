# is_need_skip_delay_interval_schema_changed

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.4 版本开始引入。</p>
</main>

## 功能描述

`is_need_skip_delay_interval_schema_changed` 用于控制当表的模式版本更改时是否需要跳过延迟间隔。

## 属性说明

|  属性    | 描述     |
|----------|---------|
| 参数类型 | 布尔类型      |
| 默认值   | False     |
| 取值范围 | <ul><li>True：跳过延迟间隔</li><li>False：不跳过延迟间隔</li></ul>  |
| 是否重启 ODP 生效 | 否  |

## 配置示例

执行如下命令，设置当表的模式版本更改时跳过延迟间隔。

```shell
obclient> alter proxyconfig set is_need_skip_delay_interval_schema_changed='True';
```
