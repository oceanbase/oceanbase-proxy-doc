# rpc_enable_requestsm_info

`rpc_enable_requestsm_info` 配置项用于控制是否打印 RPC 请求信息。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.5 版本开始引入。</p>
</main>

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   布尔类型      |
| 默认值   | False     |
| 取值范围 | <ul><li>True：打印 RPC 请求信息。</li><li>False：不打印 RPC 请求信息。</li></ul>  |
| 是否重启 ODP 生效 | 否  |
