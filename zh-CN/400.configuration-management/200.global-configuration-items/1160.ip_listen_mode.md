# ip_listen_mode

`ip_listen_mode` 用于设置 ODP 监听模式。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项从 V4.3.4 版本开始废弃。您可以查询并修改该配置项，但是该配置项并不会生效。</p>
</main>

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   整数类型      |
| 默认值   | 1     |
| 取值范围 | <ul><li>1：表示 IPv4 监听模式</li><li>2：表示 IPv6 监听模式</li><li>3：表示 IPv4 和 IPv6 监听模式</li></ul>  |
| 是否重启 ODP 生效 | 是  |
