# enable_reroute

## 功能描述

`enable_reroute` 用于判断是否开启二次路由，即在第一次路由未命中的情况下，重新将请求转发到对应 OBServer 节点。

## 属性说明

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   布尔类型      |
| 默认值   | False     |
| 取值范围 | <ul><li>True：开启二次路由</li><li>False：不开启二次路由</li></ul>  |
| 是否重启 ODP 生效 | 否  |

## 配置示例

* **场景一：普通的二次路由配置**

  * 开启二次路由功能

    ```shell
    obclient> ALTER PROXYCONFIG SET enable_reroute = True;
    ```

  * 开启 ODP 与 OceanBase 数据库之间的协议，以 OceanBase 2.0 协议为例

    ```shell
    obclient> ALTER PROXYCONFIG SET server_protocol = 'OceanBase 2.0';
    ```

* **场景二：全局索引的二次路由配置**

  * 开启二次路由功能

    ```shell
    obclient> ALTER PROXYCONFIG SET enable_reroute = True;
    ```

  * 开启 ODP 与 OceanBase 数据库之间的协议，以 OceanBase 2.0 协议为例

    ```shell
    obclient> ALTER PROXYCONFIG SET server_protocol = 'OceanBase 2.0';
    ```

  * 开启基于全局索引键的全局索引表路由

    ```shell
    obclient> ALTER PROXYCONFIG SET enable_index_route = True;
    ```
