# rpc_request_server_entry_max_retries

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.0 版本开始引入。</p>
</main>

## 功能描述

`rpc_request_server_entry_max_retries` 用于设置 RPC 请求在与数据库交互过程中失败重试次数。

## 属性说明

|  属性    | 描述     |
|----------|---------|
| 参数类型 | 整数类型      |
| 默认值   | 3     |
| 取值范围 | [1, +∞)  |
| 是否重启 ODP 生效 | 否  |

## 配置示例

执行如下命令，设置 RPC 请求在与数据库交互过程中的失败重试次数为 5 次。

```shell
obclient> alter proxyconfig set rpc_request_server_entry_max_retries= 5;
```
