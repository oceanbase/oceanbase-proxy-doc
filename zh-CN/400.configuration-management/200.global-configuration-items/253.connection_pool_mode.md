# connection_pool_mode

`connection_pool_mode` 配置项用于控制是否启用连接池功能，目前仅支持配置启用会话级连接池。启用会话级连接池后，ODP 可缓存与 OceanBase 数据库的会话。

<main id="notice" type='explain'>
   <h4>说明</h4>
   <ul>
   <li><p>该配置项自 4.3.5 版本开始引入。</p></li>
   <li><p>会话连接池功能需要与 OceanBase 数据库配合使用，若连接的 OceanBase 数据库版本不支持会话连接池功能，该配置项配置为 <code>True</code> 时也不会使用会话连接池。</p></li>
   </ul>
</main>

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   字符串类型      |
| 默认值   | ""，表示不启用连接池功能     |
| 取值范围 | <ul><li>空字符串：不启用连接池功能</li><li><code>session</code>：启用会话级连接池功能</li></ul>  |
| 是否重启 ODP 生效 | 否  |

## 示例

为 ODP 开启会话连接池功能：

```sql
obclient> alter proxyconfig set connection_pool_mode='session';
```
