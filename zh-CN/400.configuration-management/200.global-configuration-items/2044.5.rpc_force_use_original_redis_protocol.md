# rpc_force_use_original_redis_protocol

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.4 版本开始引入。</p>
</main>

## 功能描述

`rpc_force_use_original_redis_protocol` 用于控制是否强制使用原生 redis 协议。

## 属性说明

|  属性    | 描述     |
|----------|---------|
| 参数类型 | 布尔类型      |
| 默认值   | True     |
| 取值范围 | <ul><li>True：强制使用原生 redis 协议。</li><li>False：不强制使用原生 redis 协议。</li></ul>  |
| 是否重启 ODP 生效 | 否  |

## 配置示例

执行如下命令，设置不强制使用原生 redis 协议。

```shell
obclient> alter proxyconfig set rpc_force_use_original_redis_protocol='False';
```
