# enable_full_link_trace

`enable_full_link_trace` 用于控制是否使用全链路追踪功能来追踪查询执行。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.1 版本开始引入。</p>
</main>

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   布尔类型      |
| 默认值   | False     |
| 取值范围 | <ul><li>True：使用全链路追踪功能来追踪查询执行</li><li>False：关闭全链路追踪功能</li></ul>  |
| 是否重启 ODP 生效 | 否  |
