# enable_stat

`enable_stat` 用于控制是否收集统计信息。

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   布尔类型      |
| 默认值   | True     |
| 取值范围 | <ul><li>True：收集统计信息</li><li>False：不收集统计信息</li></ul>  |
| 是否重启 ODP 生效 | 否  |
