# rpc_redis_operation_timeout

`rpc_redis_operation_timeout` 配置项用于设置 OBKV-Redis 请求默认的超时时间，单位为 us。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.2 BP1 版本开始引入。</p>
</main>

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   整数类型      |
| 默认值   | 10000000    |
| 取值范围 | [0, UINT64_MAX] <main id="notice" type='explain'><h4>说明</h4><p>UINT64_MAX 表示 2 的 64 次方减一，即值为 18446744073709551615。</p></main>  |
| 是否重启 ODP 生效 | 否  |
