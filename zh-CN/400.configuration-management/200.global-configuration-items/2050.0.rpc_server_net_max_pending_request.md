# rpc_server_net_max_pending_request

`rpc_server_net_max_pending_request` 配置项用于设置后端连接中待发送请求的数量。若 `rpc_server_net_invalid_time_us` 时间内达到设置数量，ODP 会认为后端连接失效，会将该连接从连接池中剔除。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.0 版本开始引入。</p>
</main>

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   整数类型      |
| 默认值   | 10     |
| 取值范围 |  [0, +∞)  |
| 是否重启 ODP 生效 | 否  |
