# session_pool_thread_schedule_interval

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.5 版本开始引入。</p>
</main>

## 功能描述

`session_pool_thread_schedule_interval` 用于设置会话池线程处理触发事件的间隔时间。

## 属性说明

|  属性    | 描述     |
|----------|---------|
| 参数类型 | 时间类型      |
| 默认值   | 1s     |
| 取值范围 | [1s, 1m]  |
| 是否重启 ODP 生效 | 否  |

## 配置示例

执行如下命令，设置线程处理事件的间隔事件为 2 秒。

```shell
obclient> alter proxyconfig set session_pool_thread_schedule_interval= 2s;
```
