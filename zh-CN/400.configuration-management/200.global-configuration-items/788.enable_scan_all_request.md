# enable_scan_all_request

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.5 版本开始引入。</p>
</main>

## 功能描述

`enable_scan_all_request` 用于控制是否在 obsharding 模式下使用 scan_all 功能。如果设置为 `false`，表示禁止 scan_all 功能，ODP 使用 scan_all 功能会报错。

## 属性说明

|  属性    | 描述     |
|----------|---------|
| 参数类型 | 布尔类型      |
| 默认值   | True     |
| 取值范围 | <ul><li>True：可使用 scan_all 功能</li><li>False：禁止 scan_all 功能</li></ul>  |
| 是否重启 ODP 生效 | 否  |

## 配置示例

执行如下命令，设置禁止 scan_all 功能。

```shell
obclient> alter proxyconfig set enable_scan_all_request='False';
```
