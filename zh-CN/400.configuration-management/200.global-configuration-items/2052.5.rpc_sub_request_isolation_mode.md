# rpc_sub_request_isolation_mode

`rpc_sub_request_isolation_mode` 用于设置 RPC 子请求处理模式，以控制子请求的处理线程，减少其对正常请求 RT 的影响。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.2 版本开始引入，并于 4.3.2 BP1 版本起将默认值由 <code>2</code> 更新为 <code>0</code>。</p>
</main>

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   整数类型      |
| 默认值   | 0     |
| 取值范围 | [0, 2]，各个值的含义如下：<ul><li><code>0</code>：不隔离子请求，将子请求交给普通线程处理。</li><li><code>1</code>：将所有子请求交给异步线程处理。</li><li><code>2</code>：由 ODP 自动调度子请求的处理线程。</li></ul>  |
| 是否重启 ODP 生效 | 否  |
