# rpc_async_pull_batch_max_size

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.1 版本开始引入。</p>
</main>

## 功能描述

`rpc_async_pull_batch_max_size` 用于设置异步拉取的最大批量大小。

## 属性说明

|  属性    | 描述     |
|----------|---------|
| 参数类型 | 整数类型      |
| 默认值   | 10     |
| 取值范围 | [2, 50]  |
| 是否重启 ODP 生效 | 是  |

## 配置示例

执行如下命令，设置异步拉取的最大批量为 20。

```shell
obclient> alter proxyconfig set rpc_async_pull_batch_max_size=20;
```
