# enable_single_leader_node_routing

`enable_single_leader_node_routing` 配置项用于控制当租户为单节点 Primary Zone 部署形态时，是否使用更高效的路由规则。

当租户在 OceanBase 集群中副本分布为 1（Leader）：1（Follower）：1（Follower），也就是单节点 Primary Zone 部署形态，并且 `enable_single_leader_node_routing` 配置为 `True` 时，ODP 在路由该租户的请求时会使用更加高效的路由规则，快速地将强读请求路由至 Leader 节点，此时 ODP 的路由转发性能将提升 20% ~ 30%。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.1 版本开始引入。</p>
</main>

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   布尔类型      |
| 默认值   | True    |
| 取值范围 | <ul><li>True：使用更高效的路由规则</li><li>False：不使用更高效的路由规则</li></ul>  |
| 是否重启 ODP 生效 | 否  |

使用该配置项时，您需了解如下情况：

* 配置项为 `True` 时，若租户的副本分布满足条件，ODP 会自动调整路由规则，不满足副本分布的租户将不会受到影响。

* 配置项为 `True` 且租户满足条件时，该租户的如下功能将无法使用，如需使用下列功能需手动将此配置项设置为 `False`。

  * 分布式事务路由

  * 复制表均衡路由

  * 弱读延迟阈值
