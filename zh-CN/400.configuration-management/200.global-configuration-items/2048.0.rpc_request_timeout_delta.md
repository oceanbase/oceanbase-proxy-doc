# rpc_request_timeout_delta

`rpc_request_timeout_delta` 配置项用于设置 ODP 内部请求处理超时时间的 delta 值。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.0 版本开始引入。</p>
</main>

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   时间类型      |
| 默认值   | 10ms     |
| 取值范围 | [0ms, 30s]  |
| 是否重启 ODP 生效 | 否  |
