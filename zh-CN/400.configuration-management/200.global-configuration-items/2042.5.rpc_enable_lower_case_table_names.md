# rpc_enable_lower_case_table_names

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.4 版本开始引入。</p>
</main>

## 功能描述

`rpc_enable_lower_case_table_names` 用于控制是否在 RPC 请求中启用 lower_case_table_names 功能。

## 属性说明

|  属性    | 描述     |
|----------|---------|
| 参数类型 | 布尔类型      |
| 默认值   | True     |
| 取值范围 | <ul><li>True：启用 lower_case_table_names 功能。</li><li>False：不启用 lower_case_table_names 功能。</li></ul>  |
| 是否重启 ODP 生效 | 否  |

## 配置示例

执行如下命令，设置在 RPC 请求中禁用 lower_case_table_names 功能。

```shell
obclient> alter proxyconfig set rpc_enable_lower_case_table_names='False';
```
