# max_syslog_file_time

`max_syslog_file_time` 用于设置存档日志的最大保留时间，设置为 `0` 表示忽略此限制。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项只在 <a href="./900.enable-syslog-file-compress.md">enable_syslog_file_compress</a> 设置为 <code>true</code> 时才生效。 </p>
</main>

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   时间类型      |
| 默认值   | 7d     |
| 取值范围 | [1s, +∞)  |
| 是否重启 ODP 生效 | 否  |

该配置项需和 [max_syslog_file_count](./1410.max-syslog-file-count.md) 配置项搭配使用，具体组合场景如下：

|  | max_syslog_file_time = 0 | max_syslog_file_time > 0  |
|---|----------------------|---------------------------|
| **max_syslog_file_count = 0** | 不清理归档日志，可适用于磁盘容量充足的场景 | 只做时间维度管理，若归档日志保留时长超过指定时间则会被删除  |
| **max_syslog_file_count > 0** | 只做空间维度管理，若归档日志文件数量超过 max_syslog_file_count 限制，则由旧到新删除日志 | 启用两个维度的双重管理，这也是推荐的最佳配置 |
