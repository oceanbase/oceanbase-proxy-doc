# rpc_force_srv_black_list

`rpc_force_srv_black_list` 配置项用于设置鉴权登录的强制黑名单，格式为 `ip:rpc_port`，多个 OBServer 节点之间使用英文分号（`;`）分隔，如 `10.10.10.1:2882;10.10.10.2:2882`。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.0 版本开始引入，并于 4.3.4 版本废弃。您可以查询并修改该配置项，但是该配置项并不会生效。</p>
</main>

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   字符串类型      |
| 默认值   | 默认为空     |
| 取值范围 | 不涉及  |
| 是否重启 ODP 生效 | 否  |
