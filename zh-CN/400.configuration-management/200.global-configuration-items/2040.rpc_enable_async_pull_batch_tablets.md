# rpc_enable_async_pull_batch_tablets

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.1 版本开始引入。</p>
</main>

## 功能描述

`rpc_enable_async_pull_batch_tablets` 用于控制是否启用异步批量拉取 tablet ID 功能。

## 属性说明

|  属性    | 描述     |
|----------|---------|
| 参数类型 | 布尔类型      |
| 默认值   | False     |
| 取值范围 | <ul><li>True：从远程异步拉取批量 tablet ID。</li><li>False：不启用异步批量拉取 tablet ID 功能。</li></ul>  |
| 是否重启 ODP 生效 | 否  |

## 配置示例

执行如下命令，设置启用异步批量拉取 tablet ID 功能。

```shell
obclient> alter proxyconfig set rpc_enable_async_pull_batch_tablets='True';
```
