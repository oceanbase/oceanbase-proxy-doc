# rpc_max_request_batch_size

`rpc_max_request_batch_size` 配置项用于设置单次发送请求中最大的 batch 数量。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.0 版本开始引入，并于 4.3.1 版本开始默认值由 <code>5</code> 调整为 <code>20</code>。</p>
</main>

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   整数类型      |
| 默认值   | 20     |
| 取值范围 | [1, +∞)  |
| 是否重启 ODP 生效 | 否  |
