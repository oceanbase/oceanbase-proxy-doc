# qa_mode_mock_public_cloud_slb_addr

`qa_mode_mock_public_cloud_slb_addr` 用于设置模拟公共云的 SLB 地址。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项从 V4.3.4 版本开始废弃。您可以查询并修改该配置项，但是该配置项并不会生效。</p>
</main>

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   字符串类型      |
| 默认值   | 127.0.0.1:33045     |
| 取值范围 | 不涉及  |
| 是否重启 ODP 生效 | 否  |
