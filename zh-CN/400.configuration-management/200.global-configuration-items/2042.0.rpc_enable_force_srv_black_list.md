# rpc_enable_force_srv_black_list

`rpc_enable_force_srv_black_list` 配置项用于控制鉴权登录是否启用强制黑名单。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.0 版本开始引入。</p>
</main>

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   布尔类型      |
| 默认值   | False     |
| 取值范围 | <ul><li>True：启用强制黑名单。</li><li>False：不启用强制黑名单。</li></ul>  |
| 是否重启 ODP 生效 | 否  |
