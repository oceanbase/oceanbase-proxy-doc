# rpc_client_net_write_timeout

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.4 版本开始引入。</p>
</main>

## 功能描述

`rpc_client_net_write_timeout` 用于设置 RPC 客户端网络写入超时阈值。

## 属性说明

|  属性    | 描述     |
|----------|---------|
| 参数类型 | 时间类型  |
| 默认值   | 60s     |
| 取值范围 | [1s, 1d]  |
| 是否重启 ODP 生效 | 否  |

## 配置示例

设置网络写入超时阈值为 80s。

```sql
obclient> alter proxyconfig set rpc_client_net_write_timeout='80s';
```
