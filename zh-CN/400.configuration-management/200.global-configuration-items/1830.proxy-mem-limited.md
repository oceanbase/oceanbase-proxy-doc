# proxy_mem_limited

`proxy_mem_limited` 用于设置 ODP 运行时内存上限。超过上限 ODP 即自动退出。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.1 版本起取值范围由 <code>[100MB, 100G]</code> 更新为 <code>[100MB, +∞)</code>。</p>
</main>

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   容量单位      |
| 默认值   | 2G     |
| 取值范围 | [100MB, +∞)  |
| 是否重启 ODP 生效 | 否  |
