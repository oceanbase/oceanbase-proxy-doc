# proxy_mem_limited

## 功能描述

`proxy_mem_limited` 用于设置 ODP 运行时内存上限。超过上限 ODP 即自动退出。

## 属性说明

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   容量单位      |
| 默认值   | 2G     |
| 取值范围 | [100MB, +∞) <main id="notice" type='explain'><h4>说明</h4><p>从 4.3.1 版本开始，取值范围由 <code>[100MB, 100G]</code> 更新为 <code>[100MB, +∞)</code>。</p></main> |
| 是否重启 ODP 生效 | 否  |

## 配置示例

* 使用 root@proxysys 用户连接 ODP 后，执行如下 SQL 命令，修改 ODP 运行时内存上限为 5 GB。
  
  ```sql
  obclient> alter proxyconfig set proxy_mem_limited= "5G";
  ```

* 通过 kill 命令临时调整内存上限为 100 GB，并取消内存分配限制。
  
  ```shell
  kill -34 <PID_OBPROXY>
  ```

  命令中的 `<PID_OBPROXY>` 表示 ODP 的进程 ID，您需根据实际的进程 ID 替换。

  <main id="notice" type='explain'>
    <h4>说明</h4>
    <p>obproxy 进程收到信号 34，会临时取消内存限制，可以作为一种运维手段。</p>
  </main>
