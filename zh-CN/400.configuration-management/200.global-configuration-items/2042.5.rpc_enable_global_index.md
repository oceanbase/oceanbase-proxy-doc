# rpc_enable_global_index

`rpc_enable_global_index` 配置项用于控制是否开启 RPC 请求对全局索引路由的支持。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.0 版本开始引入。</p>
</main>

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   布尔类型      |
| 默认值   | False     |
| 取值范围 | <ul><li>True：开启 RPC 请求对全局索引路由的支持</li><li>False：不开启 RPC 请求对全局索引路由的支持</li></ul>  |
| 是否重启 ODP 生效 | 否  |
