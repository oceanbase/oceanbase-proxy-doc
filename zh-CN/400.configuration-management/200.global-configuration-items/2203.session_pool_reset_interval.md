# session_pool_reset_interval

`session_pool_reset_interval` 配置项用于设置向连接池中未重置的会话发送 `COM_RESET_CONNECTION` 的时间间隔。重置完成后，ODP 不会再向已重置过的会话发送 `COM_RESET_CONNECTION`。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <ul>
  <li><p>该配置项自 4.3.5 版本开始引入。</p></li>
  <li><p>不推荐修改该配置项，建议保持默认值。</p></li>
  </ul>
</main>

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   时间类型      |
| 默认值   | 10m    |
| 取值范围 | [0s, 1d]  |
| 是否重启 ODP 生效 | 否  |

## 示例

设置发送 `COM_RESET_CONNECTION` 的时间间隔为 30 分钟：

```sql
obclient> alter proxyconfig set session_pool_reset_interval='30m';
```
