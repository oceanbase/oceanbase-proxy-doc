# enable_auto_restart

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.0 版本开始引入。</p>
</main>

## 功能描述

`enable_auto_restart` 用于控制当 ODP 持有的内存达到 `proxy_mem_limited` 的 80% 时是否自动重启。

## 属性说明

|  属性    | 描述     |
|----------|---------|
| 参数类型 | 布尔类型      |
| 默认值   | False     |
| 取值范围 | <ul><li>True：自动重启</li><li>False：不自动重启</li></ul>  |
| 是否重启 ODP 生效 | 否  |

## 配置示例

执行如下命令，设置 ODP 持有内存达到 `proxy_mem_limited` 的 80% 时自动重启。

```shell
obclient> alter proxyconfig set enable_auto_restart='True';
```
