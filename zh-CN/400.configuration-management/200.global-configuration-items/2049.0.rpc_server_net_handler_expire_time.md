# rpc_server_net_handler_expire_time

`rpc_server_net_handler_expire_time` 配置项用于设置后端连接请求处理超时时间。若发送请求后指定时间无响应，ODP 会认为连接异常，会将该连接从连接池中剔除。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.0 版本开始引入。</p>
</main>

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   时间类型      |
| 默认值   | 1d     |
| 取值范围 | [0s, 10d]  |
| 是否重启 ODP 生效 | 否  |
