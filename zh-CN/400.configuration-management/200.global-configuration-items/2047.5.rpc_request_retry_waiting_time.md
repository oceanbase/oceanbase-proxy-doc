# rpc_request_retry_waiting_time

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.0 版本开始引入。</p>
</main>

## 功能描述

`rpc_request_retry_waiting_time` 用于设置 RPC 请求重试等待时间。

## 属性说明

|  属性    | 描述     |
|----------|---------|
| 参数类型 | 时间类型      |
| 默认值   | 1ms     |
| 取值范围 | [0ms, 10s]  |
| 是否重启 ODP 生效 | 否  |

## 配置示例

执行如下命令，设置 RPC 请求重试等待时间为 2 毫秒。

```shell
obclient> alter proxyconfig set rpc_request_retry_waiting_time= 2ms;
```
