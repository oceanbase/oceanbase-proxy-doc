# mysql_client_num

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.0 版本开始引入。</p>
</main>

## 功能描述

`mysql_client_num` 用于设置代理 MySQL 客户端数量。

## 属性说明

|  属性    | 描述     |
|----------|---------|
| 参数类型 | 整数类型      |
| 默认值   | 64     |
| 取值范围 | [1, 128]  |
| 是否重启 ODP 生效 | 否  |

## 配置示例

执行如下命令，设置代理 MySQL 客户端数量为 128。

```shell
obclient> alter proxyconfig set mysql_client_num=128;
```
