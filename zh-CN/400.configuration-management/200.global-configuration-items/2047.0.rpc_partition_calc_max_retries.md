# rpc_partition_calc_max_retries

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.5 版本开始引入。</p>
</main>

## 功能描述

`rpc_partition_calc_max_retries` 用于设置 RPC 请求在路由计算失败时重试次数。

## 属性说明

|  属性    | 描述     |
|----------|---------|
| 参数类型 | 整数类型      |
| 默认值   | 5     |
| 取值范围 | [0, 50]  |
| 是否重启 ODP 生效 | 否  |

## 配置示例

执行如下命令，设置 RPC 请求在路由计算失败时最多重试 10 次。

```shell
obclient> alter proxyconfig set rpc_partition_calc_max_retries= 10;
```
