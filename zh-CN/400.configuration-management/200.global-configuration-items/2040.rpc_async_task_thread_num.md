# rpc_async_task_thread_num

`rpc_async_task_thread_num` 用于设置 OBKV 异步线程的数量，旨在降低子请求转发以及大请求解析对普通请求的影响。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.2 版本开始引入。</p>
</main>

|  属性    | 描述     |
|----------|---------|
| 参数类型 | 整数类型  |
| 默认值   | 8     |
| 取值范围 | [0, 128]，取值为 `0` 时，线程数为 `实际工作线程数/2`。  |
| 是否重启 ODP 生效 | 是  |
