# request_buffer_length

`request_buffer_length` 用于设置每个请求分配的请求缓存的最大长度。当请求大小超过该阈值时，ODP 直接使用 tunnel 流式转发客户端请求。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 V4.3.4 版本起默认值由 <code>4KB</code> 更新为 <code>8KB</code>。</p>
</main>

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   容量单位      |
| 默认值   | 8KB    |
| 取值范围 | [1KB, 16MB]  |
| 是否重启 ODP 生效 | 否  |
