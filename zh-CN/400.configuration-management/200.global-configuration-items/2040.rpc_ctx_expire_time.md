# rpc_ctx_expire_time

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.1 版本开始引入。</p>
</main>

## 功能描述

`rpc_ctx_expire_time` 用于设置 RPC 登录相关信息过期时间，取值为 `0` 时表示永不过期。如果 RPC 登录相关信息在指定时间内未被访问，将被删除。

## 属性说明

|  属性    | 描述     |
|----------|---------|
| 参数类型 | 时间类型      |
| 默认值   | 1d     |
| 取值范围 | [0, +∞)  |
| 是否重启 ODP 生效 | 否  |

## 配置示例

执行如下命令，设置 RPC 登录相关信息过期时间为 2 天。

```shell
obclient> alter proxyconfig set rpc_ctx_expire_time= 2d;
```
