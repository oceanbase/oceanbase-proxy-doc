# rpc_redis_max_monitor_num

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.3 版本开始引入。</p>
</main>

## 功能描述

`rpc_redis_max_monitor_num` 用于设置 OBKV-Redis 的最大监控数量。

## 属性说明

|  属性    | 描述     |
|----------|---------|
| 参数类型 | 整数类型      |
| 默认值   | 30     |
| 取值范围 | [0, +∞)  |
| 是否重启 ODP 生效 | 否  |

## 配置示例

执行如下命令，设置 OBKV-Redis 的最大监控数量为 40。

```shell
obclient> alter proxyconfig set rpc_redis_max_monitor_num= 40;
```
