# enable_cross_shard_txn

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.0 版本开始引入。</p>
</main>

## 功能描述

`enable_cross_shard_txn` 用于控制是否允许 ODP 在事务中跨分片处理分片读取请求。

## 属性说明

|  属性    | 描述     |
|----------|---------|
| 参数类型 | 布尔类型      |
| 默认值   | True     |
| 取值范围 | <ul><li>True：允许处理分片读取请求</li><li>False：不允许处理分片读取请求</li></ul>  |
| 是否重启 ODP 生效 | 否  |

## 配置示例

执行如下命令，设置允许 ODP 在事务中跨分片处理分片读取请求。

```shell
obclient> alter proxyconfig set enable_cross_shard_txn='False';
```
