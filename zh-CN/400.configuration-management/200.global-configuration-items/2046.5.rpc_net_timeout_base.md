# rpc_net_timeout_base

`rpc_net_timeout_base` 配置项用于设置基准发送速率，即 1B 数据的发送时间，单位为 `ms`。最低带宽为 200Bps，若配置速率低于 200Bps，后端连接会发生异常，ODP 会将该连接从连接池中剔除。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.0 版本开始引入。</p>
</main>

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   整数类型      |
| 默认值   | 5     |
| 取值范围 | [0, +∞)  |
| 是否重启 ODP 生效 | 否  |
