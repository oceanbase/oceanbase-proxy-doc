# enable_crash_error_log

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.5 版本开始引入。</p>
</main>

## 功能描述

`enable_crash_error_log` 用于控制是否在 ODP 程序发生 coredump 时捕获 Linux 系统的 SIGABRT、SIGBUS、SIGFPE、SIGSEGV 信号。取值为 `True` 时，会捕捉信号并将出发 coredump 的堆栈打印到日志中。

## 属性说明

|  属性    | 描述     |
|----------|---------|
| 参数类型 | 布尔类型      |
| 默认值   | True     |
| 取值范围 | <ul><li>True：启用 ODP 捕获 CRASH 信号功能</li><li>False：不启用 ODP 捕获 CRASH 信号功能</li></ul>  |
| 是否重启 ODP 生效 | 是  |

## 配置示例

执行如下命令，设置关闭 ODP 捕获 CRASH 信号功能。

```shell
obclient> alter proxyconfig set enable_crash_error_log='False';
```
