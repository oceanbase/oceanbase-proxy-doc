# qos_stat_item_limit

`qos_stat_item_limit` 用于设置 ODP QoS 统计项数目。

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   整数类型      |
| 默认值   | 3000     |
| 取值范围 | [0, 10000]  |
| 是否重启 ODP 生效 | 否  |
