# rpc_service_mode

`rpc_service_mode` 配置项用于控制是否开启 OBKV-Redis 访问。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.2 BP1 版本开始引入。</p>
</main>

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   整数类型      |
| 默认值   | 3     |
| 取值范围 | 可取值为 1、2、3，具体含义如下：<ul><li><p><code>1</code>：仅支持 OBKV（OBKV-Table 和 OBKV-HBase）。</p></li><li><p><code>2</code>：仅支持 OBKV-Redis。</p></li><li><p><code>3</code>：同时支持 OBKV 和 OBKV-Redis 协议访问。</p></li></ul>  |
| 是否重启 ODP 生效 | 否  |
