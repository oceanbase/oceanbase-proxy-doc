# rpc_period_task_interval

`rpc_period_task_interval` 配置项用于设置 ODP 处理 RPC 周期任务的时间间隔。处理 RPC 任务主要清理前端和后端处于无效状态的请求。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.0 版本开始引入。</p>
</main>

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   时间类型      |
| 默认值   | 600s     |
| 取值范围 | [1ms, 1d]  |
| 是否重启 ODP 生效 | 否  |
