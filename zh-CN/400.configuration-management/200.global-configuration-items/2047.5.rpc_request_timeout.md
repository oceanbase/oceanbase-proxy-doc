# rpc_request_timeout

`rpc_request_timeout` 配置项用于设置请求发送的超时时间，单位 `us`。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.0 版本开始引入。</p>
</main>

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   整数类型      |
| 默认值   | 5000000     |
| 取值范围 | [0, +∞)  |
| 是否重启 ODP 生效 | 否  |
