# rpc_redis_default_user_name

`rpc_redis_default_user_name` 配置项用于设置单 AUTH password 的场景下的，访问 OBKV-Redis 的用户名（username@tenant#cluster 格式）。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>该配置项自 4.3.2 BP1 版本开始引入。</p>
</main>

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   字符串类型      |
| 默认值   | default     |
| 取值范围 | 大小不超过 256 字节的字符串  |
| 是否重启 ODP 生效 | 否  |
