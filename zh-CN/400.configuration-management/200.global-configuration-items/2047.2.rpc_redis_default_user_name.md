# rpc_redis_default_user_name

`rpc_redis_default_user_name` 配置项用于设置单 AUTH password 的场景下的，访问 OBKV-Redis 的用户名。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <ul>
  <li><p>该配置项自 4.3.2 BP1 版本开始引入，并且用户名必须为 <code>user_name@tenant_name#cluset_name</code> 格式。</p></li>
  <li><p>该配置项自 4.3.3 版本起支持仅配置为 <code>user_name<code> 格式。</p></li>
  </ul>
</main>

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   字符串类型      |
| 默认值   | default     |
| 取值范围 | 大小不超过 256 字节的字符串  |
| 是否重启 ODP 生效 | 否  |
