# session_pool_idle_timeout

`session_pool_idle_timeout` 配置项用于设置会话空闲超时时间，即会话被放回连接池后可以保留的最大时长。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <ul>
  <li><p>该配置项自 4.3.5 版本开始引入。</p></li>
  <li><p>不推荐修改该配置项，建议保持默认值。</p></li>
  </ul>
</main>

|  属性    | 描述     |
|----------|---------|
| 参数类型 |   时间类型      |
| 默认值   | 5m    |
| 取值范围 | [0s, 1d]  |
| 是否重启 ODP 生效 | 否  |

## 示例

设置会话空闲超时时间为 30 分钟：

```sql
obclient> alter proxyconfig set session_pool_idle_timeout='30m';
```
