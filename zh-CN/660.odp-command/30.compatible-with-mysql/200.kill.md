# KILL

## 描述

该语句用来终止一个会话，每次只能终止一个会话。

## 权限要求

如果您拥有 `PROCESS` 权限，则您可以查看所有会话。如果您拥有 `SUPER` 权限，您可以逐一终止所有会话和语句。否则，您只能查看和终止您自己的会话和语句。管理员可以逐一终止所有会话和语句。

  普通用户默认只能kill当前用户下所有session， 其他租户下session对其不可见，相同租户下其他用户的session的kill与否根据其当前租户权限确定.
    observer的系统租户SYS可以kill本租户内任意一个session，proxy的超级管理员root@proxysys可以kill所有cluster、tenant下的session

## 语法

```sql
KILL [CONNECTION | QUERY ] proceselist_id
```
<!-- query 的作用是 终止正在进行的 SQL 查询么，那 proceselist_id 需要指定为什么 -->
## 参数介绍

| 参数  | 描述  |
|-------|------|
| KIll  |      |
| KILL CONNECTION  | 与不含修改符的 `KILL` 一样，可根据配置的 Client Session ID 终止指定会话。  |
<!-- | KILL QUERY   | kill query掉指定proceselist_id的session。 |--没看懂 -->
| proceselist_id  | 当前会话的 Client Session ID，该 ID 是会话在客户端中的唯一标识。可以通过 `SHOW PROCESSLIST;` 或者 `SHOW PROXYSESSION;` 命令查询，输出中的 `Id` 即为 proceselist_id。  |

  可以kill掉指定proceselist_id的session

  ○ 以下三种情况时将不支持kill query，返回 ERROR 1235 (0A000): Not supported feature or function
    ■ 处于事务中时, 如begin
    ■ 当前sql依赖上一条sql执行结果时，如select found_rows()/ select row_count()/ show errors/ show warnings等
    ■ 已经指定下一条transaction特性时，如set transaction xxx

## 示例

1. 使用 root@proxysys 用户通过 ODP 连接登录 OceanBase 数据库

   ```shell
   obclient -h10.10.10.1 -uroot@proxysys -P2883 -p -c -A
   ```

   此处仅为示例，您需根据实际情况修改 IP（`-h`）和端口（`-P`）。

2. 查看客户端连接，获取 `cs_id`

   ```shell
   SHOW PROCESSLIST;
   ```

   输出如下，返回结果中的 `Id` 即为 `cs_id`。

   ```shell
   +------------+----------+------+---------------------+-----------+-------------+-------------------+-------------------+--------+--------+
   | Id         | Tenant   | User | Host                | db        | trans_count | svr_session_count | state             | tid    | pid    |
   +------------+----------+------+---------------------+-----------+-------------+-------------------+-------------------+--------+--------+
   | 1607745580 | proxysys | root | 10.10.10.1:12472    | NULL      |           0 |                 0 | MCS_ACTIVE_READER | 108100 | 108071 |
   | 1607729162 | sys      | root | 10.10.10.1:12174    | oceanbase |           0 |                 1 | MCS_ACTIVE_READER | 108071 | 108071 |
   +------------+----------+------+---------------------+-----------+-------------+-------------------+-------------------+--------+--------+
   ```

3. 终止会话

   ```shell
   kill connection 1607745580;
   ```

   输出如下：

   ```shell
   ERROR 1317 (70100): Query execution was interrupted
   ```

   使用 `SHOW PROCESSLIST;` 命令查看时，客户端会重新建立 Session 连接，并执行 SQL 显示结果，示例如下：

   ```shell
   ERROR 2006 (HY000): OceanBase server has gone away
   No connection. Trying to reconnect...
   Connection id:    1607745581
   Current database: oceanbase

   +------------+----------+------+---------------------+-----------+-------------+-------------------+-------------------+--------+--------+
   | Id         | Tenant   | User | Host                | db        | trans_count | svr_session_count | state             | tid    | pid    |
   +------------+----------+------+---------------------+-----------+-------------+-------------------+-------------------+--------+--------+
   | 1607745581 | proxysys | root | 10.10.10.1:3984     | NULL      |           0 |                 0 | MCS_ACTIVE_READER | 108100 | 108071 |
   | 1607729162 | sys      | root | 10.10.10.1:12174    | oceanbase |           0 |                 1 | MCS_ACTIVE_READER | 108071 | 108071 |
   +------------+----------+------+---------------------+-----------+-------------+-------------------+-------------------+--------+--------+
   ```
