# ALTER

## 描述

该语句用于修改 ODP 内部指定配置项的值。

## 语法

```sql
ALTER PROXYCONFIG SET key=value
```
<!-- 好像也有新增 replace into 命令修改配置项，这个也是 ODP 内部命令么，如果是的话需要补充相关材料 -->
语法说明：

* 更新配置项时，若找不到指定的配置项，或更新值为无效值，会返回相应错误码。

* value 支持使用单引号（`'value'`）或双引号（`"value"`）。

* ODP 中的配置项分为两种存放方式：一种存放方式是注册到 `ob_all_proxy_config` 表中，同时本地也会存在；另一种存放方式是仅存放在本地。
  <!-- 这个表是 OB 的表，还是 ODP 特有的表，ODP 中是否需要补充介绍一部分 ODP 特有的表信息 -->
* 更新本地配置项不会同步到 `ob_all_proxy_config` 表中，仅为本地修改；而更新 `ob_all_proxy_config` 表中的配置项，更新会同步到本地，本地中的对应配置项会和 `ob_all_proxy_config` 表中保持一致。

## 示例

1. 查看待修改配置项的值

   ```shell
   show proxyconfig like 'client_tcp_keepidle';
   ```

   输出如下：

   ```shell
   +---------------------+-------+-------------------------------------------------------------------------------------+-------------+---------------+
   | name                | value | info                                                                                | need_reboot | visible_level |
   +---------------------+-------+-------------------------------------------------------------------------------------+-------------+---------------+
   | client_tcp_keepidle | 5     | client tcp keepalive idle time, unit is second, 0 means use default value by kernel | false       | USER          |
   +---------------------+-------+-------------------------------------------------------------------------------------+-------------+---------------+
   ```

2. 修改配置项的值

   ```shell
   alter proxyconfig set client_tcp_keepidle=6;
   ```

3. 再次查看修改后配置项的值

   ```shell
   show proxyconfig like 'client_tcp_keepidle';
   ```

   输出如下：

   ```shell
   +---------------------+-------+-------------------------------------------------------------------------------------+-------------+---------------+
   | name                | value | info                                                                                | need_reboot | visible_level |
   +---------------------+-------+-------------------------------------------------------------------------------------+-------------+---------------+
   | client_tcp_keepidle | 6     | client tcp keepalive idle time, unit is second, 0 means use default value by kernel | false       | USER          |
   +---------------------+-------+-------------------------------------------------------------------------------------+-------------+---------------+
   ```
