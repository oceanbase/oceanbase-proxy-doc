# ping

## 描述

该语句用于检验 ODP 是否可用。建议使用 ODP 超级管理员 root@proxysys 用户执行该命令，其他用户在节点宕机情况下可能无法登陆 ODP。

## 语法

```sql
ping proxy
```

## 示例

```sql
ping proxy;
```

输出如下，正常情况下该命令始终回复 OK 包，当回应 ERROR 包时，代表 ODP 不能正常工作，需要人工介入重启。典型ERROR 包有：`exceed memory limit`，`Got signal. Aborting!`。

```shell
Query OK, 0 rows affected
```
