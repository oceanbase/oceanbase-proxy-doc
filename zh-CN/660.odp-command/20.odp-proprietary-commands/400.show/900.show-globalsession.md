# SHOW GLOBALSESSION

## 描述

该语句用于展示会话连接池中的会话信息。

## 权限要求

仅可使用 root@sys 用户和 root@proxysys 用户执行该命令。其中，root@sys 用户可以查看本集群内所有租户下的会话，ODP 的超级管理员 root@proxysys 可以查看所有集群、租户下的会话。

## 语法

```sql
SHOW GLOBALSESSION [ATTRIBUTE [all | 'db_key']]
```

## 参数解释

| 参数  | 描述  |
|-------|------|
| SHOW GLOBALSESSION | 展示会话连接池的统计信息。 |
| ATTRIBUTE | 可选项，配置后将展示会话连接池中会话的详细信息。  |
| [all \| 'db_key']  | 可选项，可配置为 `all` 或指定对应租户：<ul><li><code>all</code>：展示会话连接池中所有的会话信息。</li><li><code>db_key</code>：指定对应租户，格式为 <code>集群名:租户名</code>，配置后将展示指定租户的会话信息。</li></ul>  |

## 示例

* 查看会话连接池中的统计信息

  ```sql
  SHOW GLOBALSESSION;
  ```

  输出如下，`test` 租户中有两条会话缓存。

  ```shell
  +-----------------+------------+---------------+
  | dbkey_name      | idle_count | idle_timeout  |
  +-----------------+------------+---------------+
  | obcluster:sys   |          0 | 1800000000000 |
  | obcluster:test  |          2 | 1800000000000 |
  +-----------------+------------+---------------+
  ```

* 查看会话连接池中指定租户的会话信息

  ```sql
  SHOW GLOBALSESSION ATTRIBUTE 'obcluster:test'\G
  ```

  输出如下：

### 字段介绍

`SHOW GLOBALSESSION` 命令输出的字段含义介绍如下表：

|       字段        |                    含义                     |
| ----------------- | ------------------------------------------- |
| dbkey_name   | 会话所属的租户，格式为 `集群名:租户名`。   |
| idle_count  | 对应租户中存在的会话数量。   |
| idle_timeout   | 会话空闲超时时间，即会话在连接池中可以保留的最大时长，单位为纳秒。保留时长由配置项 [session_pool_idle_timeout](../../../400.configuration-management/200.global-configuration-items/2200.session_pool_idle_timeout.md) 控制。  |

`SHOW GLOBALSESSION ATTRIBUTE` 命令输出的字段含义介绍如下表：

|       字段        |                    含义                     |
| ----------------- | ------------------------------------------- |
| dbkey_name        | 会话所属的租户，格式为 `集群名:租户名`。                            |
| auth_user         | 会话连接所用的用户，格式为 `用户名@租户名#集群名`。                       |
| server_ip         | 会话对应的 OBServer 节点地址。              |
| local_ip          | 会话对应的 ODP 地址。               |
| session_state     | 会话状态，目前仅存在 `KEEP_ALIVE_GLOBAL_SHARED` 一种状态。 |
| server_session_id | OceanBase 数据库识别会话使用的唯一 ID。            |
| ss_id             | ODP 识别会话使用的唯一 ID。             |
| create_time       | 会话创建时间。                              |
| last_release_time | 会话上次被放入连接池的时间。                |
| timeout_time      | 会话过期时间，会话过期后将会被从连接池中删除。                      |
