# KILL PROXYSESSION

## 描述

该语句用来终止服务端连接。

## 权限要求

普通用户默认只能终止当前用户下所有会话， 其他租户下会话对其不可见，相同租户下其他用户的会话是否可以终止需根据其当前租户权限确定。OceanBase 数据库的系统租户（sys 租户）可以终止本租户内任意一个会话，ODP 的超级管理员 root@proxysys 可以终止所有集群、租户下的会话。

## 语法

```sql
KILL PROXYSESSION {cs_id | connection_id} ss_id
```

## 参数介绍

| 参数  | 描述  |
|-------|------|
| cs_id  | cs_id 为 ODP 内标记每个 Client Session 的 ID 号，可以通过 `SHOW PROCESSLIST;` 或者 `SHOW PROXYSESSION;` 命令查询，输出中的 `Id` 即为 cs_id。     |
| connection_id  | connection_id 为整个 OceanBase 数据库标记的每个 Client 的 ID 号。MySQL 模式下的 connection_id 通过 `SELECT CONNECTION_ID();` 语句获取，Oracle 模式下的 connection_id 通过 `SHOW FULL PROCESSLIST;` 语句获取。<main id="notice" type='explain'><h4>说明</h4><p>当 <a href="../../../400.configuration-management/200.global-configuration-items/135.client-session-id-version.md">client_session_id_version</a> 设置为 <code>2</code> 时，cs_id 会和 connection_id 保持一致。</p></main>  |
| ss_id  | ODP 标记 Server Session 的 ID 号，可以通过 `SHOW PROXYSESSION ATTRIBUTE` 命令查看。  |

## 示例

1. 使用 root@sys 用户通过 ODP 连接登录 OceanBase 数据库

   ```shell
   obclient -h10.10.10.1 -uroot@sys#obdemo -P2883 -p -c -A
   ```

   此处仅为示例，您需根据实际情况进行修改，详细的连接操作指引可参见 [通过 OBClient 连接 OceanBase 租户（MySQL 模式）](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000000508045)。

2. 查看客户端连接，获取 `cs_id`

   ```shell
   SHOW PROCESSLIST;
   ```

   输出如下，返回结果中的 `Id` 即为 `cs_id`。

   ```shell
   +------------+-------------+---------------------+-----------+---------+------+--------+------------------+
   | Id         | User        | Host                | db        | Command | Time | State  | Info             |
   +------------+-------------+---------------------+-----------+---------+------+--------+------------------+
   | 1607729164 | proxyro     | 10.10.10.1:47366    | oceanbase | Sleep   |    2 | SLEEP  | NULL             |
   | 1607729162 | root        | 10.10.10.1:47362    | oceanbase | Query   |    0 | ACTIVE | SHOW PROCESSLIST |
   +------------+-------------+---------------------+-----------+---------+------+--------+------------------+
   ```

3. 根据获取的 `cs_id` 获取 `ss_id`

   ```shell
   SHOW PROXYSESSION ATTRIBUTE 1607729162 LIKE "%id%";
   ```

   输出如下。

   ```shell
   +------------------------+--------------------+----------------+
   | attribute_name         | value              | info           |
   +------------------------+--------------------+----------------+
   | proxy_sessid           | 838175719856210097 | cs common      |
   | cs_id                  | 1607729162         | cs common      |
   | tid                    | 108071             | cs common      |
   | pid                    | 108071             | cs common      |
   | idc_name               |                    | cs common      |
   | last_insert_id_version | 0                  | cs var version |
   | server_sessid          | 3221555468         | last used ss   |
   | ss_id                  | 299                | last used ss   |
   | last_insert_id_version | 0                  | last used ss   |
   +------------------------+--------------------+----------------+
   ```

4. 终止客户端连接上的服务端连接

   ```shell
   KILL PROXYSESSION 1607729162 299;
   ```
