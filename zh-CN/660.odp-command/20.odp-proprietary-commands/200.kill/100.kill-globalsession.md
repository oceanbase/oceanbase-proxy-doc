# KILL GLOBALSESSION

## 描述

该语句用来终止会话连接池中的会话。

## 权限要求

仅可使用 root@sys 用户和 root@proxysys 用户执行该命令。其中，root@sys 用户可以终止本集群内所有租户下的会话，ODP 的超级管理员 root@proxysys 可以终止所有集群、租户下的会话。

## 语法

```sql
KILL GLOBALSESSION 'dbkey' [ss_id]
```

## 参数介绍

| 参数  | 描述  |
|-------|------|
| 'dbkey'  | 指定对应租户，格式为 <code>集群名:租户名</code>，若命令中仅配置 `dbkey`，执行后将终止指定租户中的所有会话。您可通过 `SHOW GLOBALSESSION` 命令查看会话连接池中的会话，具体介绍可参见 [SHOW GLOBALSESSION](../400.show/900.show-globalsession.md)。     |
| ss_id  | ODP 识别会话使用的唯一 ID，可以通过 `SHOW GLOBALSESSION` 命令查看，具体介绍可参见 [SHOW GLOBALSESSION](../400.show/900.show-globalsession.md)。可通过配置 `ss_id` 指定终止某一个会话。  |

## 示例

1. 使用 root@sys 用户通过 ODP 连接登录 OceanBase 数据库

   ```shell
   obclient -h10.10.10.1 -uroot@sys#obdemo -P2883 -p -c -A
   ```

   此处仅为示例，您需根据实际情况进行修改，详细的连接操作指引可参见 [通过 OBClient 连接 OceanBase 租户（MySQL 模式）](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000002013251)。

2. 查看会话连接池中的会话信息

   此处以指定查看 `test` 租户为例，您可根据实际情况执行：

   ```sql
   SHOW GLOBALSESSION ATTRIBUTE 'obcluster:test'\G
   ```

3. 终止指定会话

   ```sql
   KILL GLOBALSESSION 'obcluster:test' 193;
   ```
