# 会话连接池

## 背景信息

ODP 自 V4.3.5 起支持会话级连接池功能，以应对业务在短连接场景下频繁与 ODP 新建连接，导致 ODP 频繁与多个 OBServer 节点建连带来的开销，提升业务短连接场景的并发性能。

## 注意事项

当出现以下任一情况时，会话连接池不可用。

* 客户端使用了 Service Name，Service Name 的具体介绍可参见 [主备租户自动路由与读写分离](../600.data-routing/450.primary-and-backup-tenant-routing.md)。

* ODP 配置项 `server_protocol` 值为 `compressed mysql`，可执行 `show proxyconfig like 'server_protocol';` 命令查看 `server_protocol` 配置项的值。

* 客户端为 Oracle 租户。

* 客户端开启过分布式事务。

* 客户端与 ODP 间使用了 OceanBase 2.0 协议。

* 客户端使用了 SSL。

* 客户端请求为 BINLOG 请求。

## 版本限制

使用该功能需保证所用 ODP 为 V4.3.5 或之后版本，OceanBase 数据库为 V4.4.0 或之后版本。

## 使用

### 配置项

您可通过修改配置项 [connection_pool_mode](../400.configuration-management/200.global-configuration-items/253.connection_pool_mode.md) 控制会话连接池的启用，例如，执行如下命令启用连接池：

```sql
obclient> alter proxyconfig set connection_pool_mode='session';
```

ODP 中同时提供了如下几个配置项用于控制会话连接池的使用，建议保持默认值：

| 配置项  | 默认值  | 含义  |
|-----|-----|-----|
| [session_pool_idle_timeout](../400.configuration-management/200.global-configuration-items/2200.session_pool_idle_timeout.md) | 5m | 用于设置会话空闲超时时间，即会话被放回连接池后可以保留的最大时长。   |
| [session_pool_reset_interval](../400.configuration-management/200.global-configuration-items/2203.session_pool_reset_interval.md) | 10m |  于设置向连接池中未重置的会话发送 `COM_RESET_CONNECTION` 的时间间隔。  |
| [session_pool_stat_log_interval](../400.configuration-management/200.global-configuration-items/2205.session_pool_stat_log_interval.md) | 1m | 用于设置会话连接池统计日志时间间隔。   |

### 运维命令

* 查看会话信息

  您可使用 `root` 用户登录集群的 `sys` 租户，执行 `SHOW GLOBALSESSION` 命令查看会话连接池中的会话信息，此处以查看指定租户的会话信息为例，具体命令介绍可参见 [SHOW GLOBALSESSION](../660.odp-command/20.odp-proprietary-commands/400.show/900.show-globalsession.md)。

  使用 `root` 用户登录集群的 `sys` 租户：

  ```shell
  [admin@obtest ~]$ obclient -uroot@sys#obcluster -h10.10.10.1 -P2883 -p
  ```

  查看会话信息：

  ```sql
  SHOW GLOBALSESSION ATTRIBUTE 'obcluster:test'\G
  ```

  输出如下：


* 终止会话

  您可使用 `root` 用户登录集群的 `sys` 租户，执行 `KILL GLOBALSESSION` 命令终止会话连接池中的会话，此处以终止指定会话为例，具体命令介绍可参见 [KILL GLOBALSESSION](../660.odp-command/20.odp-proprietary-commands/200.kill/100.kill-globalsession.md)。

  使用 `root` 用户登录集群的 `sys` 租户：

  ```shell
  [admin@obtest ~]$ obclient -uroot@sys#obcluster -h10.10.10.1 -P2883 -p
  ```

  终止会话：

  ```sql
   KILL GLOBALSESSION 'obcluster:test' 193;
   ```

   示例中的 `193` 为执行 `SHOW GLOBALSESSION` 命令查看会话时，输出中的 `ss_id`，您可根据实际查看到的值进行替换。
