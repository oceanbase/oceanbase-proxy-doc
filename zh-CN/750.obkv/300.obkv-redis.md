# ODP 支持 OBKV-Redis 协议能力

## 背景介绍

OBKV-Redis 是 OceanBase 数据库自 4.2.5 版本开始支持的能力，它是基于 OceanBase 数据库开发的完全兼容 Redis 协议的持久化缓存数据库。OBKV-Redis 旨在解决传统 Redis + RDS 成本高昂、可伸缩性差、运维和管理复杂、数据一致性和安全性难以保证等痛点。OBKV-Redis 的 P99 在 10 ms 以内，满足 80% 场景的时延以及吞吐。OBKV-Redis 的详细介绍可参见官网《OceanBase 数据库》文档 [OBKV-Redis](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000001516160) 章节。

ODP 自 V4.3.0 起增加了 RPC 服务端口（默认为 `2885`）来提供 no-SQL 请求的代理服务，自 V4.3.2 BP1 起支持 OBKV-Redis 的服务能力，正式提供 RESP 服务能力（复用当前的 RPC 服务端口），并且当前已经完整支持 RESP 协议兼容处理，支持用户使用原生的 RESP 协议访问 OBKV-Redis 持久化能力（业务不需要替换 SDK）。

## 主要特点

ODP 支持 OBKV-Redis 协议能力主要有如下特点：

* RPC 服务端口：在支持 OBKV 请求的基础上，也支持 RESP 连接进行访问。

* 协议命令支持：当前支持 OBKV-Redis 绝大部分的协议命令的处理。

* 原生兼容性：支持使用原生的 RESP 客户端或驱动进行访问。

## 使用场景

目前 ODP 中该功能主要有如下两类使用场景：

* 公有云未来持久化 Redis 服务能力的场景。

* 私有云、开源用户 RESP 协议业务场景。

## 操作示例

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>本节仅简单给几个操作示例，具体连接介绍可参见官网《OceanBase 数据库》中 <a href="https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000001850968">连接 OBKV-Redis 并鉴权</a>。</p>
</main>

本节以 OBKV-Redis 用户为 `obcluster` 集群 `test` 租户下的 `root` 用户，且 ODP 的 IP 为 `10.10.10.1`，RPC 端口为 `2885` 为例，介绍如何通过 ODP 连接 OBKV-Redis。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>您需注意实际环境中 redis-cli 版本，redis-cli 版本小于 V6.0.0 时，仅可执行连接默认用户的连接串。redis-cli 版本为 V6.0 或之后版本时，您可使用如下任一连接串。</p>
</main>

* 连接默认用户

  ```shell
  redis-cli -h <ODP_IP> -p <RPC_PORT> -a <user_password>
  # example
  redis-cli -h 10.10.10.1 -p 2885 -a ********
  ```

  `-a` 用于指定用户密码，默认用户由 ODP 配置项 [rpc_redis_default_user_name](../400.configuration-management/200.global-configuration-items/2047.2.rpc_redis_default_user_name.md) 设置。

* 通过 `--user` 选项指定用户

  ```shell
  redis-cli -h <ODP_IP> -p <RPC_PORT> --user <user_name>@<tenant_name>#<cluster_name> -a <user_password>
  # example
  redis-cli -h 10.10.10.1 -p 2885 --user root@test#obcluster -a ********
  ```

  `--user` 用于指定用户，`-a` 用于指定用户密码，您需根据实际情况将 `--user` 和 `-a` 配置为对应的用户名和密码。

| GETSET      | 设置指定键的新值，并返回旧值。              | GETSET key value                   |
| INCR        | 将键的值加上 1。                           | INCR key                           |
