# ODP 支持流量控制

## 背景介绍

目前客户端以及 OceanBase 数据库均有流量控制能力，为了整个链路的稳定性，ODP 也需要支持流控能力。因此为了提升 ODP 的稳定性，同时尽可能减少流控对用户的影响，ODP 自 4.3.2 版本起根据 RPC 占用内存的情况进行流量控制。

## 功能说明

当 RPC 请求相关内存达到:::bubble 设定阈值 #[rpc_throttle_trigger_percentage](../400.configuration-management/300.multi-level-configuration-items/2040.rpc_throttle_trigger_percentage.md):::时开启限流，开启限流后会根据:::bubble 触发限流时的 QPS 限制 #[rpc_throttle_limit_qps_qa](../400.configuration-management/300.multi-level-configuration-items/2039.rpc_throttle_limit_qps_qa.md):::进行限流，大于该 QPS 的请求会根据用户设置的:::bubble 等待时间 #[rpc_request_throttle_waiting_time](../400.configuration-management/300.multi-level-configuration-items/2038.rpc_request_throttle_waiting_time.md):::等待一段时间后继续读取，整个限流过程不会向用户返回错误。

## 注意事项

* 使用该功能时需确保所使用的 ODP 为 V4.3.2 或之后版本。

* 使用该功能前需确保 [enable_obproxy_rpc_service](../400.configuration-management/200.global-configuration-items/675.enable_obproxy_rpc_service.md) 配置为 `true`。

* 若开启限流后内存仍不断增长，达到全部内存的 70% 时会停止读取请求并打印日志，等内存压力下降后继续读取。

## 使用示例

1. 使用 `root@sys` 用户通过 ODP 代理登录 OceanBase 数据库，或使用 `root@proxysys` 用户登录 ODP。

   使用 `root@sys` 用户登录 OceanBase 数据库示例如下，详细参数介绍可参见《OceanBase 数据库》文档 [通过 OBClient 连接 OceanBase 租户](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000001050310)。

   ```shell
   [admin@obtest ~]$ obclient -uroot@sys#obcluster -h10.10.10.1 -P2883 -p
   ```

   <main id="notice" type='notice'>
     <h4>注意</h4>
     <p>若要在 OceanBase 数据库中使用 ODP 命令，连接 OceanBase 数据库的连接 IP（<code>-h</code>）和连接端口（<code>-P</code>）需为 ODP 的地址和监听端口（<code>listen_port</code>）。</p>
   </main>

   使用 `root@proxysys` 用户登录 ODP 示例如下，此处的连接 IP（`-h`）为 ODP 的地址，连接端口（`-P`）为 ODP 的监听端口（`listen_port`）。

   ```shell
   [admin@obtest ~]$ obclient -uroot@proxysys -h10.10.10.1 -P2883 -p
   ```

2. 开启流控功能

   ```shell
   obclient> alter proxyconfig set enable_rpc_throttle=true;
   ```

3. 修改限流触发阈值

   ```shell
   obclient> alter proxyconfig set rpc_throttle_trigger_percentage= 40;
   ```

4. 修改限流等待时间

   ```shell
   obclient> alter proxyconfig set rpc_request_throttle_waiting_time= 10ms;
   ```

5. 修改触发限流时 QPS 的大小

   ```shell
   obclient> alter proxyconfig set rpc_throttle_limit_qps_qa= 500;
   ```
