## V4.3.0

### 版本信息

### 版本定位

ODP V4.3.0 是 ODP 4.x 系列的一个里程碑版本，在原有 SQL 代理能力的基础上，新增 OBProxy-OBKV（RPC）代理能力，两类代理服务融合到一个版本，同时支持 SQL 和 RPC 能力。

* SQL 代理新增支持使用 SERIAL 作为分区键路由、支持 `server_id` 和 `server_uuid` 系统变量转发到 binlog 服务节点、兼容 MySQL 通信协议命令字等功能，进一步完善 MySQL 兼容能力；同时优化了多级配置项和压缩协议实现，提升产品稳定性。

* RPC 代理新增 ObTableLSOpRequest 请求类型，提升 batch 模式下的处理效率；支持异步 Query 请求，优化大数据集结果下的流式处理能力。

### 关键特性说明

#### SQL 和 RPC 代理能力融合

OceanBase 数据库支持 OBKV 能力，提供通过 API 接口方式访问 Table 模型/Hbase 模型，为用户提供简单高效的 API 访问接口。为支持 OBKV 能力，ODP 在已有 SQL代理能力基础上，增加了 RPC 服务端口，用于提供 RPC 请求的代理服务，主要提供 RPC 请求的接收、处理、路由转发功能，白名单访问以及连接数并发控制能力，还通过 OBKV 扩展请求支持旁路导入能力。

ODP 启动时，默认同时开启 SQL 和 RPC 服务端口对外提供服务（默认 SQL 服务端口为 `2883`，默认 RPC 服务端口为 `2885`），支持通过 `-s`/`--rpc_listen_port` 自定义指定 RPC 服务端口。

#### 多级配置优化

ODP 提供了多级别配置管理的方式。除支持设置全局配置项外，ODP 还支持设置集群、租户、访问地址三个级别的配置项，能够针对不同级别生效，做到了定制与隔离，使得每个用户都能满足自己的需求，并且相互不干扰。同时 ODP 提供了查看、修改配置项等运维手段，提高配置项管理易用性。

ODP V4.3.0 对配置项的使用、内存和性能进行了优化，提升了用户使用体验。

#### 异步 Query 请求支持

ODP 早期版本仅支持单分区情况下的 ObTableQueryAsync 请求，对跨分区的异步 Query 会报错拦截。但是 go-client 的所有 Query 请求都是基于异步 Query 实现，因此，ODP V4.3.0 版本新支持了跨分区的异步 Query 请求，使得 go-client 能够连接 ODP 正常处理 Query 请求。

#### ObTableLSOpRequest 请求支持

在 OceanBase 数据库 V4.2.1 BP4 及之后的版本，OBKV 支持了一种新的消息格式 ObTableLSOpRequest。通过 ObTableLSOpRequest 可以实现高效操作并节省资源，具体如下：

1. 实现 LS 级别的操作汇聚，因为 OceanBase 数据库 4.x 架构是通过日志流来组织多个副本，基于 LS 的粒度能实现更大的操作汇聚，同时可以节省事务的开销，一个 ObTableLSOpRequest 只开启一个事务执行。

2. 减少消息的种类，当前 OBKV 所有支持的操作都可以通过 ObTableLSOpRequest 来传递，并且便于我们实现批量操作（如 checkAndInsUp 的批量操作）。

3. 节省消息的 RPC 传输开销，通过列名字典编码和客户端 object 格式优化实现。

现有的 queryAndMute 无法完全满足这一要求，因此 ODP V4.3.0 设计了一种新的单操作格式以及相应的批量格式，来承载 checkAndInsUp 的语义，支持 ObTableLSOpRequest 请求。

### 兼容性变更

#### 产品行为变更

新增启动选项 `-s`（`--rpc_listen_port`），用于指定 RPC 服务端口，如果不指定则默认对 2885 端口进行监听。

#### 运维命令变更

* `show proxyconfig` 增加 `range` 字段表示配置项取值范围，增加 `config_level` 表示配置项支持到的最小配置级别。

* 增加 `show proxyconfig all` 命令，查看内存中的多级别配置项的值。

### 支持的 OceanBase 数据库版本

支持 OceanBase 数据库 4.x 和 3.x 以及更低版本。根据使用的 OceanBase 数据库版本不同，对应推荐如下：

* 当 OceanBase 数据库为 3.x 版本及更低版本时，建议使用 ODP V3.2.11。

* 当 OceanBase 数据库为 4.x 版本时，有如下两种情况。

  * 若使用过程中依赖新功能，推荐使用 ODP V4.3.0。

  * 若使用过程中不依赖新功能，推荐使用 ODP V4.2.1（LTS 版本）。
