# OceanBase 数据库代理社区版 V4.3.2

## V4.3.2 BP1

### 版本信息

* 发布时间：2024 年 12 月 11 日

* 版本号：V4.3.2 BP1

* RPM 版本号：obproxy-ce-4.3.2.0-42

### 发版目的

支持 OBKV-Redis 能力，具体介绍可参见 [ODP 支持 OBKV-Redis 协议能力](../../../750.obkv/300.obkv-redis.md)。

### 缺陷修复

* 修复 OBKV 暴露分区接口的处理的问题。

* 修复 OBKV 租户不存在场景下的刷新过程。

* 修复 OBKV 跨分区子请求，异常场景下的稳定问题。

## V4.3.2

### 版本信息

* 发布时间：2024 年 10 月 23 日

* 版本号：V4.3.2

* RPM 版本号：obproxy-ce-4.3.2.0-26

### 发版目的

* 支持基于权重的动态负载均衡功能，具体介绍可参见 [基于权重的负载均衡](../../../600.data-routing/400.intra-tenant-routing/1100.weight-based-load-balancing.md)。

* ODP 支持列存副本路由，具体配置可参见配置项 [route_target_replica_type](../../../400.configuration-management/300.multi-level-configuration-items/2040.route_target_replica_type.md)

* 支持设置只读流量不自动发送给只读副本。

* MySQL 模式下支持 Double 类型路由。

* 支持将 OceanBase 数据库能力集合传递给 JDBC。

* SQL 防火墙功能进行修改、完善，具体介绍可参见 [ODP SQL 防火墙](../../../900.o-m-guide/700.odp-sql-firewall.md)。

* 支持 MySQL 非法日期类型路由。

* 支持 GCP 的 PPv2 协议头，支持一段式。

* 性能优化二期。

* 内存稳定性提升。

* PS 场景和 Promethus 监控性能优化。

* 兼容 MySQL 静态变量 port。

* 支持 `select last_trace_id()` 语句做特殊路由。

* `SHOW MASTER STATUS` 支持注解。

* 支持 AWS 支持 ppv2（OB-RPC）。

* 支持 OBKV 异步化请求处理解析和封装处理框架。

* 支持 OBKV 大结果集优化。

* OBKV 支持 substring_index 生成列作为分区键。

* OBKV 优化 sharding 子请求处理过程。

* 支持 OBKV PPv2 测试。

* 支持 OBKV 暴露分区接口能力。

### 缺陷修复

* 修复租户指定大小写敏感，ODP 获取 Location 信息失败，无法准确路由的问题。

* 创建租户指定 lower_case_table_names 可能触发的断连问题。

* 修复一些异常场景下 ODP core 的问题。

* 修复 ODP 对 REQUEST_TENANT_NOT_IN_SERVER_ERROR 错误码进行重试的问题

* 修复 Drop 租户再重新创建租户后，HBASE ODP 模式可能出现的重试超时问题。
