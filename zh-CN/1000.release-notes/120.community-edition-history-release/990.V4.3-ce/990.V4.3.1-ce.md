# OceanBase 数据库代理社区版 V4.3.1

## V4.3.1

### 版本信息

* 发布时间：2024 年 08 月 06 日

* 版本号：V4.3.1

* RPM 版本号：obproxy-ce-4.3.1.0-4

### 发版目的

* 支持 OBKV 能力，具体介绍可参见 [ODP 支持 RPC 服务端口](../../../750.obkv/100.obkv-rpc.md)。

* ODP 2884 端口提供新建连接统计数据。

* 兼容 MySQL 5.7 数据类型 SERIAL。

* 通信协议命令字补全。

* 优化压缩协议实现，提升 OceanBase 2.0 协议稳定性。

* 配置实现优化。

* 支持 server_id、server_uuid 等系统变量转发到 Binlog 实例。

* 支持 client_ip、proxy_version 等属性在 handshake response 时传递给 Binlog 实例。

* ODP 内存超限行为修改。

* ODP Prometheus 监控完善。

* mock MySQL 语法 BINLOG Statement、SHOW RELAYLOG EVENTS、SHOW SLAVE HOSTS 和 SHOW SLAVE STATUS，具体介绍可参见 [MySQL 兼容命令](../../../660.odp-command/30.compatible-with-mysql/100.binlog.md)。

* 配置项 `binlog_service_ip` 支持域名以及多地址，具体介绍可参见 [binlog_service_ip](../../../400.configuration-management/300.multi-level-configuration-items/40.binlog-service_ip.md)。

* 单机模式下，降低 ODP 的 CPU 使用。

* 支持表锁功能。

* 支持 OceanBase 数据库 4.x 版本的主备库功能，具体介绍可参见 [主备租户自动路由](../../../600.data-routing/450.primary-and-backup-tenant-routing.md)。

* 支持 ASCII 字符集。

* 支持 utf8mb4 字符集下 utf8mb4_0900_ai_ci 字符序。

* 支持配置项 `proxy_primary_zone_name` 指定多个 Zone，具体介绍可参见 [proxy_primary_zone_name](../../../400.configuration-management/300.multi-level-configuration-items/1840.proxy-primary-zone-name.md)。

* 支持 ODP 识别 dblink 语句，不走分布式事务路由。

* 完整支持 LSOP 能力。

* 支持 batch 请求和 LSOP 请求 return one result 优化。

* Hbase 模式增加 tablegroup 支持，支持多 famliy。

* 支持 OBKV 请求路由信息批量获取。

* OBKV 请求协议解析优化，简化解析流程。

* 优化 OBKV 请求依赖的 dummy_ldc。

* OBKV 将 session 信息与连接依赖解耦以及优化路由。

* OBKV HBASE 代理支持基于 substring 的 Key 分区路由。

* Hbase 支持 substring_index 生成列作为分区键。

### 缺陷修复

* 修复 metadb 拉配置和 root@proxyro 集群密码修改并发，导致异常配置写入，登录失败的问题。

* 修复 Prometheus 数据打印数据库名错误的问题。

* 修复 ObLatch 报错加锁失败的问题。

* 修复 load data local 导入卡住的问题。

* 修复 obloader V4.3 使用旁路导入功能，导入数据失败的问题。

* 修复 Java 客户端异步 query 返回的 session id 不合理，导致校验失败的问题。

* 修复跨分区情况下超时不会返回 server 错误码的问题。

* 修复 lsop 容灾场景下疑似 OB_CONCURRENCY_OBJ_POOL 内存泄漏的问题。

* 修复 lsop 场景下 OB_SE_ARRAY 模块内存泄漏的问题。

* 修复修改客户端使 query 查询超时，ODP 触发 core 的问题。

* 修复连接 ODP，二合一协议下，JDBC 执行 begin 语句夯住的问题。

* 修复创建备集群后连接失败，报错 `cluster name does not match to` 的问题。

* 修复 Binlog 没有携带 connect attr 的问题。

* 修复 COM_STMT_SEND_LONG_DATA 连接断开后，ODP 需要断开客户端连接的问题。
