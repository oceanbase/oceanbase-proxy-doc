# OceanBase 数据库代理社区版 V4.2.3

## V4.2.3

### 版本信息

* 发布时间：2024 年 03 月 07 日

* 版本号：V4.2.3

* RPM 版本号：obproxy-ce-4.2.3.0-3

### 发版目的

* 支持路由语句路由诊断，具体介绍可参见 [路由诊断](../../../600.data-routing/400.intra-tenant-routing/100.overview-of-routing.md) 章节。

* 支持断连接诊断，具体介绍可参见 [连接诊断](../../../900.o-m-guide/500.connection-diagnosis.md)。

* 支持 SSL 控制 TLS 版本，只使用 TLS1.2 或者 TLS1.3。

* 支持 Binlog 地址变更。

* 支持 AWS 支持 ppv2。

### 缺陷修复

* 修复 OBClient GBK 乱码问题。

* 修复指定 IP 功能异常端口断连接未报错的问题。

* 修复 ODP 开启高可用开关后，会出现概率性链接 Binlog 服务失败的问题。

* 修复 PS 内存泄漏导致程序退出的问题。

* 修复 Binlog 请求的场景下，集群信息过期导致断连接的问题。

* 修复连接诊断相关内存泄漏，导致 ODP 资源耗尽，进程退出的问题。
