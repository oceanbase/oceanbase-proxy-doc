# protocol_diagnosis_level

`protocol_diagnosis_level` specifies whether to enable protocol diagnostics and whether to output the diagnostic information to logs.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is introduced since OceanBase Database Proxy (ODP) V4.2.3. </p>
</main>

| Attribute | Description |
|----------|---------|
| Parameter type | Integer |
| Default value | 0 |
| Value range | 0, 1, and 2.<ul><li>0: indicates to disable protocol diagnostics. </li><li>1: indicates to enable protocol diagnostics and to output protocol diagnostic information together with connection diagnostic information to obproxy_diagnosis.log upon disconnection. </li><li>2: indicates to enable protocol diagnostics, output protocol diagnostic information together with connection diagnostic information to obproxy_diagnosis.log upon disconnection, and output INFO-level diagnostic information to obproxy.log after the execution of each request. </li></ul>  |
