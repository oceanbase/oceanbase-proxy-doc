# session_pool_reset_interval

The `session_pool_reset_interval` parameter specifies the interval at which ODP sends the `COM_RESET_CONNECTION` command to a session that has not been reset in the connection pool. After a session is reset, ODP does not send the `COM_RESET_CONNECTION` command to the session again.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <ul>
  <li><p>This parameter is introduced in ODP 4.3.5. </p></li>
  <li><p>We recommend that you do not modify this parameter and keep it at the default value. </p></li>
  </ul>
</main>

| Attribute | Description |
|----------|---------|
| Parameter type | Time type |
| Default value | 10m |
| Value range | [0s, 1d] |
| Effective only after ODP restart | No |

## Examples

To set the interval at which ODP sends the `COM_RESET_CONNECTION` command to a session that has not been reset in the connection pool to 30 minutes, execute the following statement:

```sql
obclient> alter proxyconfig set session_pool_reset_interval='30m';
```
