# rpc_enable_global_index

`rpc_enable_global_index` specifies whether to enable the support by RPC requests for global index routing.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is introduced since ODP V4.3.0. </p>
</main>

| Attribute | Description |
|----------|---------|
| Parameter type | Boolean |
| Default value | False |
| Value range | <ul><li>`True`: specifies to enable the support by RPC requests for global index routing.</li><li>`False`: specifies to disable the support by RPC requests for global index routing.</li></ul> |
| Effective only after ODP restart | No |
