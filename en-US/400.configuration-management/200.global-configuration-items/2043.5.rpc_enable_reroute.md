# rpc_enable_reroute

`rpc_enable_reroute` specifies whether to enable RPC rerouting.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is introduced since ODP V4.3.0. </p>
</main>

| Attribute | Description |
|----------|---------|
| Parameter type | Boolean |
| Default value | True |
| Value range | <ul><li>`True`: specifies to enable RPC rerouting. </li><li>`False`: specifies to disable RPC rerouting. </li></ul> |
| Effective only after ODP restart | No |
