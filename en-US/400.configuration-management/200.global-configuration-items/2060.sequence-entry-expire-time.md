# sequence_entry_expire_time

`sequence_entry_expire_time` specifies the validity period of sequences.

| Attribute | Description |
|----------|---------|
| Parameter type | INTERVAL |
| Default value | 1d |
| Value range | [0s, 1d] |
| Effective only after ODP restart | No |
