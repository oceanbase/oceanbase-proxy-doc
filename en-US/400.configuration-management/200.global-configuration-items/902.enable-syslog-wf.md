# enable_syslog_wf

`enable_syslog_wf` specifies whether to print ODP logs at or above the WARN level in `obproxy.log` to a separate log file (`obproxy.log.wf`).

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is introduced since OceanBase Database Proxy (ODP) V4.2.3. </p>
</main>

| Attribute | Description |
|---------|--------------------------------------|
| Parameter type | Boolean |
| Default value | False |
| Value range | <ul><li>`True`: indicates to print logs at or above the WARN level in `obproxy.log` to a separate log file.</li><li>`False`: indicates not to print logs at or above the WARN level in `obproxy.log` to a separate log file.</li></ul> |
| Effective only after ODP restart | No |
