# rpc_enable_sub_req_log

`rpc_enable_sub_req_log` controls whether qualifying OBKV sub-requests are logged in `obproxy_slow.log` and `obproxy_digest.log`.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter does not affect SQL workloads.</p>
</main>

| Attribute | Description |
|----------|---------|
| Parameter type | Boolean |
| Default value | True |
| Value range | <ul><li>True: log qualifying OBKV sub-requests</li><li>False: do not log them</li></ul> |
| Effective only after ODP restart | No |

## Examples

If sub-request logging hurts performance, disable it:

```sql
obclient> alter proxyconfig set rpc_enable_sub_req_log='False';
```
