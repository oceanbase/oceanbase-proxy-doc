# session_pool_stat_log_interval

The `session_pool_stat_log_interval` parameter specifies the interval at which statistics of the session connection pool are logged.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <ul>
  <li><p>This parameter is introduced in ODP 4.3.5. </p></li>
  <li><p>We recommend that you do not modify this parameter. </p></li>
  </ul>
</main>

| Attribute | Description |
|----------|---------|
| Parameter type | Time type |
| Default value | 1m |
| Value range | [0s, 1d] |
| Effective only after ODP restart | No |

## Examples

To set the interval at which statistics of the session connection pool are logged to 5 minutes, execute the following statement:

```sql
obclient> alter proxyconfig set session_pool_stat_log_interval='5m';
```
