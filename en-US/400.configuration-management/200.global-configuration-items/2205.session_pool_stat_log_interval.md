# session_pool_stat_log_interval

`session_pool_stat_log_interval` sets the interval for session pool statistics logging.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <ul>
  <li><p>This parameter is introduced in ODP V4.3.5.</p></li>
  <li><p>Changing it is not recommended; keep the default unless necessary.</p></li>
  </ul>
</main>

| Attribute | Description |
|----------|---------|
| Parameter type | Time |
| Default value | 1m |
| Value range | [0s, 1d] |
| Effective only after ODP restart | No |

## Examples

Set the statistics log interval to 5 minutes:

```sql
obclient> alter proxyconfig set session_pool_stat_log_interval='5m';
```
