# rpc_redis_operation_timeout

`rpc_redis_operation_timeout` specifies the default timeout period for a request to an OBKV-Redis database, in μs.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter was introduced in OceanBase Database Proxy (ODP) V4.3.2 BP1.</p>
</main>

|Attribute                       |Description                                                                                                                                  |
|--------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------|
|Parameter type                  |Integer                                                                                                                                      |
|Default value                   |10000000                                                                                                                                     |
|Value range                     |[0, UINT64_MAX] <main id="notice" type='explain'><h4>Note</h4><p>UINT64_MAX indicates 2^64 minus 1, namely 18446744073709551615.</p></main>|
|Effective only after ODP restart|No                                                                                                                                           |
