# rpc_enable_async_pull_batch_tablets

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is introduced in ODP V4.3.1.</p>
</main>

## Description

`rpc_enable_async_pull_batch_tablets` controls whether to enable asynchronous batch pulls of tablet IDs.

## Attributes

| Attribute | Description |
|----------|---------|
| Parameter type | Boolean |
| Default value | False |
| Value range | <ul><li>True: pull tablet IDs from remote in batches asynchronously</li><li>False: disable asynchronous batch pulls</li></ul> |
| Effective only after ODP restart | No |

## Examples

Run the following command to enable asynchronous batch tablet pulls:

```shell
obclient> alter proxyconfig set rpc_enable_async_pull_batch_tablets='True';
```
