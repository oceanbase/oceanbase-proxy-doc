# rpc_enable_async_pull_batch_tablets

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is available starting from ODP 4.3.1. </p>
</main>

## Description

`rpc_enable_async_pull_batch_tablets` specifies whether to enable the asynchronous batch tablet ID pull feature.

## Attributes

|  Attribute  | Description     |
|----------|---------|
| Parameter type | Boolean      |
| Default value | False     |
| Value range | <ul><li>True: Asynchronously pull tablet IDs from a remote node. </li><li>False: Do not enable the asynchronous batch tablet ID pull feature. </li></ul>  |
| Effective only after ODP restart | No  |

## Examples

Run the following command to enable the asynchronous batch tablet ID pull feature.

```shell
obclient> alter proxyconfig set rpc_enable_async_pull_batch_tablets='True';
```
