# rpc_request_timeout_delta

`rpc_request_timeout_delta` specifies the delta value of the timeout period for processing a request within ODP.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is introduced since ODP V4.3.0. </p>
</main>

| Attribute | Description |
|----------|---------|
| Parameter type | Time |
| Default value | 10ms |
| Value range | [0ms, 30s] |
| Effective only after ODP restart | No |
