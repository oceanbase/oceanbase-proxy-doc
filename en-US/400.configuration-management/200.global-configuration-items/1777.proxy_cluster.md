# proxy_cluster

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is available starting from ODP 4.2.3. </p>
</main>

## Description

`proxy_cluster` specifies the name of the ODP cluster to which the ODP belongs.

## Attributes

| Attribute | Description |
|----------|---------|
| Parameter type | String |
| Default value | undefined |
| Value range | N/A |
| Whether ODP restart is required | No |

## Examples

Run the following command to set the ODP cluster name to `test`.

```shell
obclient> alter proxyconfig set proxy_cluster='test';
```
