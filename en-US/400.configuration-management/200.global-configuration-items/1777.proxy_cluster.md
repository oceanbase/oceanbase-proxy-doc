# proxy_cluster

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is available starting from ODP 4.2.3. </p>
</main>

## Description

`proxy_cluster` specifies the name of the ODP cluster to which the current ODP belongs.

## Attributes

| Attribute | Description |
|----------|---------|
| Parameter type | String type      |
| Default value   | undefined     |
| Value range | N/A  |
| Effective only after ODP restart | No  |

## Examples

Run the following command to set the ODP cluster name to `test`.

```shell
obclient> alter proxyconfig set proxy_cluster='test';
```
