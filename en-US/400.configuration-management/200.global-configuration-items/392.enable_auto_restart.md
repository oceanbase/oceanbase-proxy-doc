# enable_auto_restart

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is available starting from ODP 4.3.0. </p>
</main>

## Description

`enable_auto_restart` specifies whether to automatically restart ODP when the memory it holds reaches 80% of the value of `proxy_mem_limited`.

## Attributes

|  Attribute  | Description     |
|----------|---------|
| Parameter type | Boolean      |
| Default value   | False     |
| Value range | <ul><li>True: automatically restart</li><li>False: do not automatically restart</li></ul>  |
| Effective only after ODP restart | No  |

## Examples

Run the following command to set ODP to automatically restart when the memory it holds reaches 80% of the value of `proxy_mem_limited`.

```shell
obclient> alter proxyconfig set enable_auto_restart='True';
```
