# enable_auto_restart

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is available starting from OceanBase Database 4.3.0. </p>
</main>

## Description

`enable_auto_restart` specifies whether to automatically restart the ODP when the memory it holds reaches 80% of the value of `proxy_mem_limited`.

## Attributes

| Attribute | Description |
|----------|---------|
| Parameter type | Boolean |
| Default value | False |
| Value range | <ul><li>True: restart automatically</li><li>False: do not restart automatically</li></ul> |
| Whether the ODP restarts | No |

## Examples

Run the following command to set the ODP to automatically restart when the memory it holds reaches 80% of the value of `proxy_mem_limited`.

```shell
obclient> alter proxyconfig set enable_auto_restart='True';
```
