# table_entry_retry_build_limit

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is available starting from ODP 4.3.4. </p>
</main>

## Description

`table_entry_retry_build_limit` specifies the maximum number of retries for ODP when building an atomic table.

## Attributes

|  Attribute   | Description     |
|----------|---------|
| Parameter type | Integer      |
| Default value   | 3     |
| Value range | [0, 10000]  |
| Effective only after ODP restart | No  |

## Examples

Run the following command to set the maximum number of retries for ODP when building an atomic table to 5.

```shell
obclient> alter proxyconfig set table_entry_retry_build_limit= 5;
```
