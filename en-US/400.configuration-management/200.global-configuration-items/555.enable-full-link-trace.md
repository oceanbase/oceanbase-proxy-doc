# enable_full_link_trace

`enable_full_link_trace` specifies whether to enable end-to-end tracing for query execution.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter was introduced in OceanBase Database Proxy (ODP) V4.3.1.</p>
</main>

|Attribute                       |Description                                                                                                                    |
|--------------------------------|-------------------------------------------------------------------------------------------------------------------------------|
|Parameter type                  |Boolean                                                                                                                        |
|Default value                   |False                                                                                                                          |
|Value range                     |<ul><li>`True`: specifies to enable end-to-end tracing.</li><li>`False`: specifies to disable end-to-end tracing.</li></ul>|
|Effective only after ODP restart|No                                                                                                                             |
