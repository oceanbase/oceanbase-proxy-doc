# rpc_sub_request_isolation_mode

`rpc_sub_request_isolation_mode` specifies the processing mode of remote procedure call (RPC) subrequests. You can set an appropriate processing mode to control the number of threads used for processing subrequests and reduce the impact on the response time of general requests.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is introduced in OceanBase Database Proxy (ODP) V4.3.2. </p>
</main>

|  Attribute    | Description     |
|----------|---------|
| Parameter type | Integer |
| Default value | 2 |
| Value range | [0, 2]. The values are described as follows: <ul><li><code>0</code>: Subrequests are not isolated and are forwarded to general threads. </li><li><code>1</code>: All subrequests are forwarded to asynchronous threads. </li><li><code>2</code>: ODP automatically schedules the threads for processing subrequests. </li></ul> |
| Effective upon ODP restart | No |
