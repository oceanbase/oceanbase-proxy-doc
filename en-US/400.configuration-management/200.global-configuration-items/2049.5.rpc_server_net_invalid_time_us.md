# rpc_server_net_invalid_time_us

`rpc_server_net_invalid_time_us` specifies the interval (in `us`) for sending pending requests in the backend connection. The default value is 10s.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is introduced since ODP V4.3.0. </p>
</main>

| Attribute | Description |
|----------|---------|
| Parameter type | Integer |
| Default value | 10000000 |
| Value range | [0, +∞) |
| Effective only after ODP restart | No |
