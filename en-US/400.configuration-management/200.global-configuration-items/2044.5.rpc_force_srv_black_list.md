# rpc_force_srv_black_list

`rpc_force_srv_black_list` specifies the blocklist for forced logon authentication in the format of `ip:rpc_port`. Separate OBServer nodes with semicolons (`;`), for example, `10.10.10.1:2882;10.10.10.2:2882`.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is introduced since ODP V4.3.0. </p>
</main>

| Attribute | Description |
|----------|---------|
| Parameter type | String |
| Default value | Empty |
| Value range | N/A |
| Effective only after ODP restart | No |
