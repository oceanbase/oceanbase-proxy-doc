# rpc_redis_default_user_name

`rpc_redis_default_user_name` specifies the username to access an OBKV-Redis database with a single AUTH password.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <ul>
  <li><p>This parameter was introduced in OceanBase Database Proxy (ODP) V4.3.2 BP1 and must be specified in the <code>user_name@tenant_name#cluster_name</code> format.</p></li>
  <li><p>In ODP V4.3.3 and later, you can specify this parameter in the <code>user_name</code> format.</p></li>
  </ul>
</main>

|Attribute                       |Description                               |
|--------------------------------|------------------------------------------|
|Parameter type                  |String                                    |
|Default value                   |default                                   |
|Value range                     |A string not exceeding 256 bytes in length|
|Effective only after ODP restart|No                                        |
