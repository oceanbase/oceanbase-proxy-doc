# rpc_request_max_retries

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is introduced in ODP 4.3.0. </p>
</main>

## Description

`rpc_request_max_retries` specifies the maximum number of retries for an RPC request when the partition lookup fails.

## Attributes

|  Attribute  | Description     |
|----------|---------|
| Parameter type | Integer      |
| Default value   | 300     |
| Value range | [1, +∞)  |
| Effective only after ODP restart | No  |

## Examples

Run the following command to set the maximum number of retries for an RPC request when the partition lookup fails to 400.

```shell
obclient> alter proxyconfig set rpc_request_max_retries= 400;
```
