# qa_mode_mock_public_cloud_slb_addr

`qa_mode_mock_public_cloud_slb_addr` specifies the SLB address for the simulated public cloud. The value is a string.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is deprecated starting from V4.3.4. You can query and modify this parameter, but it will not take effect. </p>
</main>

|  Attribute    | Description     |
|----------|---------|
| Parameter type |   String      |
| Default value   | 127.0.0.1:33045     |
| Value range | N/A  |
| Effective only after ODP restart | No  |
