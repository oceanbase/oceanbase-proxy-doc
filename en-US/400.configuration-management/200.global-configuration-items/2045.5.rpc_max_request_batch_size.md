# rpc_max_request_batch_size

`rpc_max_request_batch_size` specifies the maximum number of requests allowed in a single batch.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter was introduced in OceanBase Database Proxy (ODP) V4.3.0. Since ODP V4.3.1, the default value has been changed from <code>5</code> to <code>20</code>. </p>
</main>

|  Attribute    | Description     |
|----------|---------|
| Parameter type | Integer |
| Default value | 20 |
| Value range | [1, +∞) |
| Effective upon ODP restart | No |
