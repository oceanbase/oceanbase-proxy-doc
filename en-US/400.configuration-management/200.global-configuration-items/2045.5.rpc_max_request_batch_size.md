# rpc_max_request_batch_size

`rpc_max_request_batch_size` specifies the maximum number of requests allowed in a single batch.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is introduced since ODP V4.3.0. </p>
</main>

| Attribute | Description |
|----------|---------|
| Parameter type | Integer |
| Default value | 5 |
| Value range | [1, +∞) |
| Effective only after ODP restart | No |
