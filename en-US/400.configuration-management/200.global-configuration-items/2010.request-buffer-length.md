# request_buffer_length

`request_buffer_length` specifies the maximum length of the request buffer allocated to each request. When the size of a client request exceeds the specified threshold, OceanBase Database Proxy (ODP) directly forwards the request over a tunnel.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>The default value of this parameter has been changed from <code>4KB</code> to <code>8KB</code> since ODP V4.3.4. </p>
</main>

|  Attribute    | Description     |
|----------|---------|
| Parameter type | Capacity |
| Default value   | 8KB    |
| Value range | [1KB, 16MB]  |
| Effective only after ODP restart | No |
