# rpc_sub_request_weight

`rpc_sub_request_weight` specifies the weight of remote procedure call (RPC) subrequests. The higher the weight, the more the general threads occupied by subrequests.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <ul>
  <li><p>This parameter is introduced in OceanBase Database Proxy (ODP) V4.3.2. </p></li>
  <li><p>This parameter takes effect only when <a href="2052.5.rpc_sub_request_isolation_mode.md">rpc_sub_request_isolation_mode</a> is set to <code>2</code>. </p></li>
  </ul>
</main>

| Attribute   | Description |
| ----------------- | -------- |
| Parameter type    | Integer |
| Default value     | 10 |
| Value range    | [0, +∞) |
| Effective upon ODP restart | No    |
