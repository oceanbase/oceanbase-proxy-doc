# rpc_redis_max_monitor_num

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is available starting from OceanBase Database 4.3.3. </p>
</main>

## Description

`rpc_redis_max_monitor_num` specifies the maximum number of monitors for OBKV-Redis.

## Attributes

|  Attribute    | Description     |
|----------|---------|
| Parameter type | Integer      |
| Default value   | 30     |
| Value range | [0, +∞)  |
| Effective only after ODP restart | No  |

## Examples

Run the following command to set the maximum number of monitors for OBKV-Redis to 40.

```shell
obclient> alter proxyconfig set rpc_redis_max_monitor_num= 40;
```
