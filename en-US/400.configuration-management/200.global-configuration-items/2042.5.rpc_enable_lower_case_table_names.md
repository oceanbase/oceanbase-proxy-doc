# rpc_enable_lower_case_table_names

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is introduced in ODP 4.3.4. </p>
</main>

## Description

`rpc_enable_lower_case_table_names` specifies whether to distinguish the case of table names in RPC requests.

## Attributes

|  Attribute  | Description     |
|----------|---------|
| Parameter type | Boolean      |
| Default value   | True     |
| Value range | <ul><li>True: Distinguish the case of table names. </li><li>False: Do not distinguish the case of table names. </li></ul>  |
| Effective only after ODP restart | No  |

## Examples

Run the following command to specify not to distinguish the case of table names in RPC requests.

```shell
obclient> alter proxyconfig set rpc_enable_lower_case_table_names='False';
```
