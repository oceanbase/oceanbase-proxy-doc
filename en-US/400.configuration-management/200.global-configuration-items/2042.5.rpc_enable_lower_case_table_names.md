# rpc_enable_lower_case_table_names

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter was introduced in OceanBase Database V4.3.4. </p>
</main>

## Description

`rpc_enable_lower_case_table_names` specifies whether the RPC requests distinguish table names in terms of case.

## Attributes

| Attribute | Description |
|----------|---------|
| Parameter type | Boolean |
| Default value | True |
| Value range | <ul><li>True: The RPC requests distinguish table names in terms of case. </li><li>False: The RPC requests do not distinguish table names in terms of case. </li></ul>  |
| Effective only after ODP restart | No  |

## Examples

Run the following command to set the RPC requests to not distinguish table names in terms of case.

```shell
obclient> alter proxyconfig set rpc_enable_lower_case_table_names='False';
```
