# rpc_enable_lower_case_table_names

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is introduced in ODP V4.3.4.</p>
</main>

## Description

`rpc_enable_lower_case_table_names` controls whether RPC requests treat table names as case-sensitive.

## Attributes

| Attribute | Description |
|----------|---------|
| Parameter type | Boolean |
| Default value | True |
| Value range | <ul><li>True: table names are case-sensitive</li><li>False: table names are not case-sensitive</li></ul> |
| Effective only after ODP restart | No |

## Examples

Run the following command to disable case sensitivity for table names in RPC requests:

```shell
obclient> alter proxyconfig set rpc_enable_lower_case_table_names='False';
```
