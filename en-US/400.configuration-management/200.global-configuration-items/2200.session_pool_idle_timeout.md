# session_pool_idle_timeout

The `session_pool_idle_timeout` parameter specifies the maximum time a session can be retained in the connection pool after it is returned to the pool. This parameter determines the idle timeout period for sessions in the connection pool.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <ul>
  <li><p>This parameter is introduced in ODP 4.3.5. </p></li>
  <li><p>We recommend that you do not modify this parameter and keep the default value. </p></li>
  </ul>
</main>

| Attribute | Description |
|----------|---------|
| Parameter type | Time type      |
| Default value | 5m    |
| Value range | [0s, 1d]  |
| Effective only after ODP restart | No  |

## Examples

Here is an example of setting the session idle timeout period to 30 minutes:

```sql
obclient> alter proxyconfig set session_pool_idle_timeout='30m';
```
