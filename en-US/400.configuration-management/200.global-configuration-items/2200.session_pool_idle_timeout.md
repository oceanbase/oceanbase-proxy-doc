# session_pool_idle_timeout

`session_pool_idle_timeout` sets the maximum idle time a session may remain in the pool after being returned.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <ul>
  <li><p>This parameter is introduced in ODP V4.3.5.</p></li>
  <li><p>Changing it is not recommended; keep the default unless necessary.</p></li>
  </ul>
</main>

| Attribute | Description |
|----------|---------|
| Parameter type | Time |
| Default value | 5m |
| Value range | [0s, 1d] |
| Effective only after ODP restart | No |

## Examples

Set idle timeout to 30 minutes:

```sql
obclient> alter proxyconfig set session_pool_idle_timeout='30m';
```
