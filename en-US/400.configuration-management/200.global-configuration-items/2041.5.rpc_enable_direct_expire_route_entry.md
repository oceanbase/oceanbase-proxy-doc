# rpc_enable_direct_expire_route_entry

`rpc_enable_direct_expire_route_entry` specifies whether to clean up expired routing information by force and not to use dirty data for asynchronous refresh.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is introduced since ODP V4.3.0. </p>
</main>

| Attribute | Description |
|----------|---------|
| Parameter type | Boolean |
| Default value | False |
| Value range | <ul><li>`True`: specifies to clean up expired routing information by force. </li><li>`False`: specifies not to clean up expired routing information by force. </li></ul> |
| Effective only after ODP restart | No |
