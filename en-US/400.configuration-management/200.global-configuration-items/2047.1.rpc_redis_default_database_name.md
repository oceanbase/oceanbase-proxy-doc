# rpc_redis_default_database_name

`rpc_redis_default_database_name` specifies the name of an OBKV-Redis physical database.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter was introduced in OceanBase Database Proxy (ODP) V4.3.2 BP1.</p>
</main>

|Attribute                       |Description                               |
|--------------------------------|------------------------------------------|
|Parameter type                  |String                                    |
|Default value                   |obkv-redis                                |
|Value range                     |A string not exceeding 256 bytes in length|
|Effective only after ODP restart|No                                        |
