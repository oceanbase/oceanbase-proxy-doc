# enable_standby

`enable_standby` specifies whether to enable the standby database (effective for OceanBase Database V3.x) or whether to enable routing to the primary and standby tenants (effective for OceanBase Database V4.2.4 and later).

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter supports controlling whether to enable routing to the primary and standby tenants from ODP V4.3.1. </p>
</main>

|  Attribute    | Description     |
|----------|---------|
| Parameter type | Boolean |
| Default value | True    |
| Value range | <ul><li>`True`: specifies to enable the standby database. </li><li>`False`: specifies not to enable the standby database. </li></ul>  |
| Effective upon ODP restart | No |
