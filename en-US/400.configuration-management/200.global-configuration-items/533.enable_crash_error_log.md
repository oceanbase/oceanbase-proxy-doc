# enable_crash_error_log

<main id="notice" type='explain'>
  <h4>Note</h4>
  <ul>
  <li><p>This parameter was introduced in V4.3.5.x in version 4.3.5. </p></li>
  <li><p>This parameter was introduced in V4.3.1.x in version 4.3.1 BP6. </p></li>
  </ul>
</main>

## Description

`enable_crash_error_log` specifies whether to capture the Linux system signals SIGABRT, SIGBUS, SIGFPE, and SIGSEGV when a coredump occurs in an ODP program. If the value is `True`, the signals are captured and the stack trace that triggered the coredump is printed to the log.

## Attributes

| Attribute | Description |
|----------|---------|
| Parameter type | Boolean |
| Default value | True |
| Value range | <ul><li>True: Enable the ODP to capture CRASH signals. </li><li>False: Disable the ODP to capture CRASH signals. </li></ul>  |
| Effective only after ODP restart | Yes  |

## Examples

Run the following command to disable the ODP from capturing CRASH signals.

```shell
obclient> alter proxyconfig set enable_crash_error_log='False';
```
