# enable_scan_all_request

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is available starting from ODP 4.3.5. </p>
</main>

## Description

`enable_scan_all_request` specifies whether to enable the scan_all feature in the obsharding mode. If you set this parameter to `false`, the scan_all feature is disabled. If you use the scan_all feature in this mode, an error is returned.

## Attributes

| Attribute | Description |
|----------|---------|
| Parameter type | Boolean |
| Default value | True |
| Value range | <ul><li>True: The scan_all feature is enabled.</li><li>False: The scan_all feature is disabled.</li></ul> |
| Effective only after ODP restart | No |

## Examples

Run the following command to disable the scan_all feature.

```shell
obclient> alter proxyconfig set enable_scan_all_request='False';
```
