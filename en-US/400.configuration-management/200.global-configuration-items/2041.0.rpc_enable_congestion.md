# rpc_enable_congestion

`rpc_enable_congestion` specifies whether to enable OBServer blocklist processing for RPC requests.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is introduced since ODP V4.3.0. </p>
</main>

| Attribute | Description |
|----------|---------|
| Parameter type | Boolean |
| Default value | False |
| Value range | <ul><li>`True`: specifies to enable OBServer blocklist processing. </li><li>`False`: specifies to disable OBServer blocklist processing. </li></ul> |
| Effective only after ODP restart | No |
