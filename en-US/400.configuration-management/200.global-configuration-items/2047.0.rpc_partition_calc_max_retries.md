# rpc_partition_calc_max_retries

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is introduced in ODP V4.3.5.</p>
</main>

## Description

`rpc_partition_calc_max_retries` sets how many times an RPC request retries when partition routing calculation fails.

## Attributes

| Attribute | Description |
|----------|---------|
| Parameter type | Integer |
| Default value | 5 |
| Value range | [0, 50] |
| Effective only after ODP restart | No |

## Examples

Run the following command to allow up to 10 retries:

```shell
obclient> alter proxyconfig set rpc_partition_calc_max_retries= 10;
```
