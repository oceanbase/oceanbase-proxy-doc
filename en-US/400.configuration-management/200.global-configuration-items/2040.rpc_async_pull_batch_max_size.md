# rpc_async_pull_batch_max_size

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is available starting from OceanBase Database 4.3.1. </p>
</main>

## Description

`rpc_async_pull_batch_max_size` specifies the size of the asynchronous batch pull partition address. Before using this parameter, make sure that the `rpc_enable_async_pull_batch_tablets` parameter is set to `True`, which enables the asynchronous batch pull tablet ID feature.

## Attributes

| Attribute | Description |
|----------|---------|
| Parameter type | Integer |
| Default value | 10 |
| Value range | [2, 50] |
| Effective only after ODP restart | Yes |

## Examples

1. Enable the asynchronous batch pull tablet ID feature.

   ```shell
   obclient> alter proxyconfig set rpc_enable_async_pull_batch_tablets='True';
   ```

2. Set the size of the asynchronous batch pull partition address to 20.

   ```shell
   obclient> alter proxyconfig set rpc_async_pull_batch_max_size=20;
   ```
