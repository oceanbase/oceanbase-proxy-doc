# rpc_async_pull_batch_max_size

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is introduced in ODP V4.3.1.</p>
</main>

## Description

`rpc_async_pull_batch_max_size` sets the batch size for asynchronous partition address pulls. Set [rpc_enable_async_pull_batch_tablets](2040.rpc_enable_async_pull_batch_tablets.md) to `True` before using this parameter.

## Attributes

| Attribute | Description |
|----------|---------|
| Parameter type | Integer |
| Default value | 10 |
| Value range | [2, 50] |
| Effective only after ODP restart | Yes |

## Examples

1. Enable asynchronous batch tablet pulls:

   ```shell
   obclient> alter proxyconfig set rpc_enable_async_pull_batch_tablets='True';
   ```

2. Set batch size to 20:

   ```shell
   obclient> alter proxyconfig set rpc_async_pull_batch_max_size=20;
   ```
