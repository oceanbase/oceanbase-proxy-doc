# routing_cache_mem_limited

`routing_cache_mem_limited` specifies the maximum memory for the routing cache of OceanBase Database Proxy (ODP), such as the table cache and address cache.

|  Attribute    | Description     |
|----------|---------|
| Parameter type | Capacity |
| Default value   | 128 MB     |
| Value range | [1 KB, 100 GB]  |
| Effective upon ODP restart | No |
