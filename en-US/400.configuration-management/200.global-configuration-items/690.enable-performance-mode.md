# enable_performance_mode

`enable_performance_mode` specifies whether to enable the performance mode. When the performance mode is enabled, additional information is logged in the ODP logs.

| Attribute | Description |
|----------|---------|
| Parameter type | Boolean |
| Default value | False |
| Value range | <ul><li>`True`: specifies to enable the performance mode.</li><li>`False`: specifies to disable the performance mode.</li></ul> |
| Effective only after ODP restart | No |
