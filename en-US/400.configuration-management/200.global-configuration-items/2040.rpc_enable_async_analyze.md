# rpc_enable_async_analyze

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is introduced in ODP 4.3.2. </p>
</main>

## Description

`rpc_enable_async_analyze` specifies whether to asynchronously parse large requests or result sets.

## Attributes

|  Attribute   | Description     |
|----------|---------|
| Parameter type | Boolean      |
| Default value   | False     |
| Value range | <ul><li>True: Asynchronously parse large requests or result sets. </li><li>False: Do not asynchronously parse large requests or result sets. </li></ul>  |
| Effective only after ODP restart | No  |

## Examples

Run the following command to enable asynchronous parsing of large requests or result sets.

```shell
obclient> alter proxyconfig set rpc_enable_async_analyze='True';
```
