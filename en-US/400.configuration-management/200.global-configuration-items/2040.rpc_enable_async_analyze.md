# rpc_enable_async_analyze

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is introduced in ODP V4.3.2.</p>
</main>

## Description

`rpc_enable_async_analyze` controls whether RPC asynchronously parses large requests or result sets.

## Attributes

| Attribute | Description |
|----------|---------|
| Parameter type | Boolean |
| Default value | False |
| Value range | <ul><li>True: parse large requests or result sets asynchronously</li><li>False: do not use asynchronous parsing</li></ul> |
| Effective only after ODP restart | No |

## Examples

Run the following command to enable asynchronous parsing for large requests or result sets:

```shell
obclient> alter proxyconfig set rpc_enable_async_analyze='True';
```
