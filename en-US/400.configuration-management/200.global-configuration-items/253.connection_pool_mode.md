# connection_pool_mode

`connection_pool_mode` controls whether connection pooling is enabled. Only session-level pooling is supported. When enabled, ODP can cache sessions to OceanBase Database.

<main id="notice" type='explain'>
   <h4>Note</h4>
   <ul>
   <li><p>This parameter is introduced in ODP V4.3.5.</p></li>
   <li><p>The session pool requires a compatible OceanBase Database version. If the database does not support the session pool, pooling is not used even when this parameter is set to <code>session</code>.</p></li>
   </ul>
</main>

| Attribute | Description |
|----------|---------|
| Parameter type | String |
| Default value | Empty string (pooling disabled) |
| Value range | <ul><li>Empty string: pooling disabled</li><li><code>session</code>: enable session-level pooling</li></ul> |
| Effective only after ODP restart | No |

## Examples

Enable the session connection pool:

```sql
obclient> alter proxyconfig set connection_pool_mode='session';
```
