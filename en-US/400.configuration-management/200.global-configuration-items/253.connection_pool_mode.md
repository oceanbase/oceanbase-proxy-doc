# connection_pool_mode

The `connection_pool_mode` parameter specifies whether to enable the connection pool feature. At present, session-level connection pooling is supported. After session-level connection pooling is enabled, ODP can cache sessions with OceanBase Database.

<main id="notice" type='explain'>
   <h4>Note</h4>
   <ul>
   <li><p>This parameter is introduced in ODP 4.3.5. </p></li>
   <li><p>The session-level connection pool feature is supported only when the OceanBase Database version supports it. If the OceanBase Database version does not support the session-level connection pool feature, the session-level connection pool feature will not be used even if this parameter is set to <code>True</code>. </p></li>
   </ul>
</main>

| Attribute | Description |
|----------|---------|
| Parameter type | String |
| Default value | "" (connection pooling is disabled) |
| Value range | <ul><li>Empty string: connection pooling is disabled. </li><li><code>session</code>: session-level connection pooling is enabled. </li></ul> |
| Effective only after ODP restart | No |

## Examples

Enable the session-level connection pool feature for ODP:

```sql
obclient> alter proxyconfig set connection_pool_mode='session';
```
