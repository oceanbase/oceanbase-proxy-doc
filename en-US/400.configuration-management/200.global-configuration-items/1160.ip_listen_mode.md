# ip_listen_mode

`ip_listen_mode` specifies the ODP listening mode.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is deprecated starting from V4.3.4. You can query and modify this parameter, but it will not take effect. </p>
</main>

|  Attribute  | Description  |
|------------|--------------|
| Parameter type | Integer  |
| Default value  | 1  |
| Value range | <ul><li>1: IPv4 listening mode</li><li>2: IPv6 listening mode</li><li>3: IPv4 and IPv6 listening mode</li></ul>  |
| Effective only after ODP restart | Yes  |
