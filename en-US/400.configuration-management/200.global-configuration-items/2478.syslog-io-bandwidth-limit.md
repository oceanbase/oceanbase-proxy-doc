# syslog_io_bandwidth_limit

`syslog_io_bandwidth_limit` specifies the upper limit of disk I/O bandwidth allowed for OceanBase Database Proxy (ODP) logging. ODP logging is throttled when its traffic exceeds the upper bandwidth limit. When throttling is triggered, the log `REACH SYSLOG RATE LIMIT` will be printed in obproxy.log.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is introduced since ODP V4.2.3. </p>
</main>

| Attribute | Description |
|----------|---------|
| Parameter type | Capacity |
| Default value | `30MB`. You need to specify the unit when you configure the parameter. The default unit is MB.  |
| Value range | NULL |
| Effective only after ODP restart | No |
