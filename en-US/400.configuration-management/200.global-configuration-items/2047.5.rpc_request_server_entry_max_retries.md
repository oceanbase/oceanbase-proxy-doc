# rpc_request_server_entry_max_retries

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is introduced in ODP V4.3.0.</p>
</main>

## Description

`rpc_request_server_entry_max_retries` sets how many times an RPC request retries when database interaction fails.

## Attributes

| Attribute | Description |
|----------|---------|
| Parameter type | Integer |
| Default value | 3 |
| Value range | [1, +∞) |
| Effective only after ODP restart | No |

## Examples

Run the following command to set retries to 5:

```shell
obclient> alter proxyconfig set rpc_request_server_entry_max_retries= 5;
```
