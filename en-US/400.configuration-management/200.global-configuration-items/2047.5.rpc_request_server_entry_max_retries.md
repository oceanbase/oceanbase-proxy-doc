# rpc_request_server_entry_max_retries

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is available starting from ODP 4.3.0. </p>
</main>

## Description

`rpc_request_server_entry_max_retries` specifies the maximum number of retries for an RPC request when an error occurs during interaction with the database.

## Attributes

|  Attribute  | Description     |
|----------|---------|
| Parameter type | Integer      |
| Default value   | 3     |
| Value range | [1, +∞)  |
| Effective only after ODP restart | No  |

## Examples

Run the following command to set the maximum number of retries for an RPC request when an error occurs during interaction with the database to 5.

```shell
obclient> alter proxyconfig set rpc_request_server_entry_max_retries= 5;
```
