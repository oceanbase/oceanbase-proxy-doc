# rpc_enable_retry_request_info_log

`rpc_enable_retry_request_info_log` specifies whether to print RPC request retry information.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is introduced since ODP V4.3.0. </p>
</main>

| Attribute | Description |
|----------|---------|
| Parameter type | Boolean |
| Default value | True |
| Value range | <ul><li>`True`: specifies to print RPC request retry information. </li><li>`False`: specifies not to print RPC request retry information. </li></ul> |
| Effective only after ODP restart | No |
