# net_accept_threads

`net_accept_threads` specifies the number of threads that run accept tasks.

| Attribute | Description |
|----------|---------|
| Parameter type | Integer |
| Default value | 2 |
| Value range | [0, 8] |
| Effective only after ODP restart | Yes |
