# tenant_location_valid_time

`tenant_location_valid_time` specifies the validity period of cached tenant information.

| Attribute | Description |
|----------|---------|
| Parameter type | INTERVAL |
| Default value | 1d |
| Value range | [0s, 100d] |
| Effective only after ODP restart | No |
