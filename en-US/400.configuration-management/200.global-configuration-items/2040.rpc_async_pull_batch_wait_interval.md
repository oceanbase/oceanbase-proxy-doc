# rpc_async_pull_batch_wait_interval

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter was introduced in OceanBase Database V4.3.1. </p>
</main>

## Description

`rpc_async_pull_batch_wait_interval` specifies the wait interval for asynchronous batch pulls.

## Attributes

|  Attribute    | Description     |
|----------|---------|
| Parameter type | Time type      |
| Default value   | 10ms     |
| Value range | [1ms, 1s]  |
| Effective only after ODP restart | No  |

## Examples

Run the following command to set the wait interval for asynchronous batch pulls to 20 ms.

```shell
obclient> alter proxyconfig set rpc_async_pull_batch_wait_interval= 20ms;
```
