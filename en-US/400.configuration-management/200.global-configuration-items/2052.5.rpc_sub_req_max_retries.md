# rpc_sub_req_max_retries

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is introduced in ODP V4.3.1.</p>
</main>

## Description

`rpc_sub_req_max_retries` sets the maximum retries for an RPC sub-request after a failure.

## Attributes

| Attribute | Description |
|----------|---------|
| Parameter type | Integer |
| Default value | 5 |
| Value range | [0, 50] |
| Effective only after ODP restart | No |

## Examples

Run the following command to allow up to 10 sub-request retries:

```shell
obclient> alter proxyconfig set rpc_sub_req_max_retries= 10;
```
