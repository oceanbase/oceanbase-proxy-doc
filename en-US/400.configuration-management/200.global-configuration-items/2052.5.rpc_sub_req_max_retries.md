# rpc_sub_req_max_retries

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is available starting from ODP 4.3.1. </p>
</main>

## Description

`rpc_sub_req_max_retries` specifies the maximum number of retries for an RPC subrequest when a request fails.

## Attributes

| Attribute | Description |
|----------|---------|
| Parameter type | Integer |
| Default value | 5 |
| Value range | [0, 50] |
| Effective only after ODP restart | Yes |

## Examples

Run the following command to set the maximum number of retries for an RPC subrequest when a request fails to 10.

```shell
obclient> alter proxyconfig set rpc_sub_req_max_retries= 10;
```
