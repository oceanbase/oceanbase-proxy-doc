# rpc_force_use_original_redis_protocol

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is introduced in ODP 4.3.4. </p>
</main>

## Description

`rpc_force_use_original_redis_protocol` specifies whether to force the use of the native Redis protocol.

## Attributes

|  Attribute  | Description     |
|----------|---------|
| Type      | Boolean      |
| Default value   | True     |
| Value range | <ul><li>True: Force the use of the native Redis protocol.</li><li>False: Do not force the use of the native Redis protocol.</li></ul>  |
| Effective only after ODP restart | No  |

## Examples

Run the following command to disable the forced use of the native Redis protocol.

```shell
obclient> alter proxyconfig set rpc_force_use_original_redis_protocol='False';
```
