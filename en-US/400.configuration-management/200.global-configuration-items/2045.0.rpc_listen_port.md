# rpc_listen_port

`rpc_listen_port` specifies the RPC service listening port.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is introduced since ODP V4.3.0. </p>
</main>

| Attribute | Description |
|----------|---------|
| Parameter type | Integer |
| Default value | 2885 |
| Value range | (1024, 65536) |
| Effective only after ODP restart | Yes |
