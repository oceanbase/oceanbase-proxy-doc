# monitor_stat_middle_threshold

`monitor_stat_middle_threshold` specifies the medium time threshold of tenant statistics.

| Attribute | Description |
|----------|---------|
| Parameter type | INTERVAL |
| Default value | 100ms |
| Value range | [0s, 30s] |
| Effective only after ODP restart | No |
