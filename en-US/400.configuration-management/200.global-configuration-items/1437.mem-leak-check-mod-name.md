# mem_leak_check_mod_name

`mem_leak_check_mod_name` specifies the names of modules to be monitored by the `show proxymemory` command, which can be names in the `mod_name` column of the command output.

| Attribute | Description |
|----------|---------|
| Parameter type | String |
| Default value | Empty string |
| Value range | `ALL` and specific module names output in the `mod_name` column by the `show proxymemory;` command. The value `ALL` indicates to monitor all modules. We recommend that you use the value `ALL` only in debugging mode. If you set the value to specific module names, only corresponding modules are monitored.  |
| Effective only after ODP restart | No |

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>The corresponding <code>mod_name</code> stacks are displayed after you run the <code>show proxymemory X\G</code> command only if you have configured this parameter. <code>X</code> in the command is specified to display top X stacks that occupy the most memory. </p>
</main>
