# monitor_stat_dump_interval

`monitor_stat_dump_interval` specifies the interval for flushing monitoring statistics to logs.

| Attribute | Description |
|----------|---------|
| Parameter type | INTERVAL |
| Default value | 1m |
| Value range | [1s, 1h] |
| Effective only after ODP restart | No |
