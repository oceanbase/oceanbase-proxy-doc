# rpc_enable_parallel_handler

`rpc_enable_parallel_handler` specifies whether to enable the asynchronous execution framework.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is introduced since ODP V4.3.0. </p>
</main>

| Attribute | Description |
|----------|---------|
| Parameter type | Boolean |
| Default value | True |
| Value range | <ul><li>`True`: specifies to enable the asynchronous execution framework. </li><li>`False`: specifies to disable the asynchronous execution framework. </li></ul> |
| Effective only after ODP restart | No |
