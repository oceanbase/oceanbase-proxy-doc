# enable_ob_protocol_v2

`enable_ob_protocol_v2` specifies whether to enable the OceanBase 2.0 protocol between OceanBase Database Proxy (ODP) and OceanBase Database. OceanBase 2.0 is a proprietary transmission protocol developed based on the MySQL compression protocol.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <ul>
  <li><p>The default value is changed from <code>False</code> to <code>True</code> since ODP V4.0.0. </p></li>
  <li><p>This parameter is deprecated in OceanBase Database V4.3.4. You can query and modify this parameter, but the setting does not take effect. </p></li>
  </ul>
</main>

| Attribute | Description |
|----------|---------|
| Parameter type | Boolean |
| Default value | True |
| Value range | <ul><li>`True`: specifies to enable the OceanBase 2.0 protocol for transmission.</li><li>`False`: specifies to disable the OceanBase 2.0 protocol for transmission.</li></ul> |
| Effective only after ODP restart | No |

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>You must not set the value to <code>False</code> in ODP V4.x. Otherwise, some features may not take effect. </p>
</main>

## Examples

1. Log on to OceanBase Database in proxy mode through OceanBase Database Proxy (ODP) as the root@sys user or log on to ODP as the root@proxysys user.

   Here is an example of logging on to OceanBase Database in proxy mode through ODP as the root@sys user. For more information about the parameters, see [Connect to an OceanBase Database tenant by using OBClient](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001104073).

   ```shell
   [admin@obtest ~]$ obclient -uroot@sys#obcluster -h10.10.10.1 -P2883 -p
   ```

   <main id="notice" type='notice'>
     <h4>Notice</h4>
     <p>To use ODP commands in OceanBase Database, the IP address (<code>-h</code>) and the connection port (<code>-P</code>) must be the address and listening port (<code>listen_port</code>) of ODP.</p>
   </main>

   Here is an example of logging on to ODP as the root@proxysys user. The IP address (`-h`) is the IP address of ODP, and the connection port (`-P`) is the listening port (`listen_port`) of ODP.

   ```shell
   [admin@obtest ~]$ obclient -uroot@proxysys -h10.10.10.1 -P2883 -p
   ```

2. Run the following command to enable the OceanBase 2.0 protocol:

   ```shell
   obclient [(none)]> alter proxyconfig set enable_ob_protocol_v2=True;
   ```
