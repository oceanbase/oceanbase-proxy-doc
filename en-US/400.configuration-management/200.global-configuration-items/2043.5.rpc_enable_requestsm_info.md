# rpc_enable_requestsm_info

`rpc_enable_requestsm_info` controls whether RPC request information is printed.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is introduced in ODP V4.3.5.</p>
</main>

| Attribute | Description |
|----------|---------|
| Parameter type | Boolean |
| Default value | False |
| Value range | <ul><li>True: print RPC request information</li><li>False: do not print RPC request information</li></ul> |
| Effective only after ODP restart | No |
