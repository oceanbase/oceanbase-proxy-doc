# rpc_enable_requestsm_info

The `rpc_enable_requestsm_info` option specifies whether to print RPC request information.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This option was introduced in ODP 4.3.5. </p>
</main>

|  Attribute | Description     |
|----------|---------|
| Parameter type | Boolean      |
| Default value   | False     |
| Value range | <ul><li>True: prints RPC request information.</li><li>False: does not print RPC request information.</li></ul>  |
| Effective only after ODP restart | No  |
