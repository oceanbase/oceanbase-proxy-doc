# session_pool_thread_schedule_interval

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is available starting from ODP 4.3.5. </p>
</main>

## Description

`session_pool_thread_schedule_interval` specifies the interval at which threads in the session pool process triggered events.

## Attributes

| Attribute | Description |
|----------|---------|
| Parameter type | Time type |
| Default value | 1s |
| Value range | [1s, 1m] |
| Effective only after ODP restart | No |

## Configuration example

Run the following command to set the interval at which threads process events to 2 seconds.

```shell
obclient> alter proxyconfig set session_pool_thread_schedule_interval= 2s;
```
