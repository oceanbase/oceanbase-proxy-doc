# mem_leak_check_class_name

`mem_leak_check_class_name` specifies the names of classes to be monitored by the `show proxymemory objpool` command, which can be names in the `free_list_name` column of the command output.

| Attribute | Description |
|----------|---------|
| Parameter type | String |
| Default value | Empty string |
| Value range | `ALL` and specific class names output in the `free_list_name` column by the `show proxymemory objpool;` command. The value `ALL` indicates to monitor all classes. We recommend that you use the value `ALL` only in debugging mode. If you set the value to specific class names, only corresponding classes are monitored.  |
| Effective only after ODP restart | No |

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>The corresponding <code>free_list_name</code> stacks are displayed after you run the <code>show proxymemory objpool X\G</code> command only if you have configured this parameter. <code>X</code> in the command is specified to display top X stacks that occupy the most memory. </p>
</main>
