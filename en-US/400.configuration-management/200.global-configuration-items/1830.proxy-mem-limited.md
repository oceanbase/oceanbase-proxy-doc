# proxy_mem_limited

`proxy_mem_limited` specifies the maximum runtime memory of OceanBase Database Proxy (ODP). ODP automatically exits when the limit is exceeded.

<main id="notice" type='explain'>
   <h4>Note</h4>
   <p>The value range of this parameter has been changed from <code>[100MB, 100G]</code> to <code>[100MB, +∞)</code> since ODP V4.3.1.</p>
</main>

| Attribute | Description |
|----------|---------|
| Parameter type | Capacity |
| Default value | 2G |
| Value range | [100MB, +∞) |
| Effective only after ODP restart | No |
