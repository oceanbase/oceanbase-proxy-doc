# enable_single_leader_node_routing

`enable_single_leader_node_routing` specifies whether to apply more efficient routing rules when a tenant is deployed in single-node primary zone mode, where the primary zone of the tenant resides on a single node.

If the replicas of a tenant are distributed in 1:1:1 (leader:follower:follower) mode in the OceanBase cluster, namely, single-node primary zone mode, and `enable_single_leader_node_routing` is set to `True`, OceanBase Database Proxy (ODP) uses more efficient routing rules to quickly route strong-consistency read requests to the leader node when it forwards the requests of this tenant. This can improve the routing and forwarding performance by 20% to 30%.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <ul><li>
  <p>This parameter is introduced in ODP V4.3.1. </p>
  </li><li>
  <p>If you set this parameter to <code>True</code> for a single-node tenant, the MySQL protocol, instead of the OceanBase 2.0 protocol, is used. If the features or components of the OceanBase 2.0 protocol are required for using ODP, you need to set this parameter to <code>False</code>. </p>
  </li></ul>
</main>

|  Attribute    | Description     |
|----------|---------|
| Parameter type | Boolean |
| Default value | True |
| Value range | <ul><li>`True`: specifies to use more efficient routing rules.</li><li>`False`: specifies not to use more efficient routing rules</li></ul>|
| Effective upon ODP restart | No |

Take note of the following considerations:

* When this parameter is set to `True`, ODP automatically adjusts the routing rules of a tenant if its replica distribution meets the conditions, and the tenants whose replica distribution does not meet the conditions are not affected.

* When this parameter is set to `True` and the replica distribution of a tenant meets the conditions, the following features of the tenant are unavailable. To use these features, you need to manually set this parameter to `False`.

  * Distributed transaction routing

  * Replicated table-based load-balanced routing

  * Latency threshold for weak-consistency reads
