# session_pool_thread_num

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is available starting from ODP 4.3.5. </p>
</main>

## Description

`session_pool_thread_num` specifies the number of threads for processing events triggered by sessions in the connection pool.

## Attributes

| Attribute | Description |
|----------|---------|
| Parameter type | Integer |
| Default value | 1 |
| Value range | [1, 128] |
| Effective only after ODP restart | Yes |

## Examples

Run the following command to set the number of threads for processing events triggered by sessions in the connection pool to 4.

```shell
obclient> alter proxyconfig set session_pool_thread_num= 4;
```
