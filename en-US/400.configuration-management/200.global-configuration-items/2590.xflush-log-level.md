# xflush_log_level

`xflush_log_level` specifies the xflush log level.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>The default value of this parameter is changed from <code>INFO</code> to <code>ERROR</code> since OceanBase Database Proxy (ODP) V4.2.3. </p>
</main>

| Attribute | Description |
|----------|---------|
| Parameter type | String |
| Default value | ERROR |
| Value range | <ul><li>`ERROR`: indicates an error. </li><li>`WARN`: indicates a warning. </li><li>`INFO`: indicates a prompt. </li><li>`EDIAG`: indicates the diagnostic information for troubleshooting. </li><li>`WDIAG`: indicates the diagnostic information for troubleshooting, which are expected errors. </li><li>`TRACE`: indicates task-level debugging information. </li><li>`DEBUG`: indicates detailed debugging information. </li></ul> |
| Effective only after ODP restart | No |

For more information about the log level, see [Overview](../../650.log/100.overview-of-logs.md).
