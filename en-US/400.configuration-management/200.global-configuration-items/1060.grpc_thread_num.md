# grpc_thread_num

`grpc_thread_num` specifies the number of GRPC threads.

| Attribute | Description |
|----------|---------|
| Parameter type | Integer |
| Default value | 8 |
| Value range | [8, 16] |
| Effective only after ODP restart | Yes |
