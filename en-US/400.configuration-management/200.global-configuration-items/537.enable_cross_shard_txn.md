# enable_cross_shard_txn

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is available starting from ODP 4.3.0. </p>
</main>

## Description

`enable_cross_shard_txn` specifies whether to allow ODP to process shard read requests across shards in a transaction.

## Attributes

|  Attribute  | Description     |
|----------|---------|
| Parameter type | Boolean      |
| Default value   | True     |
| Value range | <ul><li>True: Allow ODP to process shard read requests across shards in a transaction. </li><li>False: Do not allow ODP to process shard read requests across shards in a transaction. </li></ul>  |
| Effective only after ODP restart | No  |

## Examples

Run the following command to allow ODP to process shard read requests across shards in a transaction.

```shell
obclient> alter proxyconfig set enable_cross_shard_txn='False';
```
