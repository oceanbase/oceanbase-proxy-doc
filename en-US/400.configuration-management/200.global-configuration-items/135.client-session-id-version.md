# client_session_id_version

`client_session_id_version` specifies the version of the format used for generating client session IDs. To use the new calculation logic, you need to set this parameter to `2`.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is introduced since OceanBase Database Proxy (ODP) V4.2.3. </p>
</main>

| Attribute | Description |
|----------|---------|
| Parameter type | Integer |
| Default value | 1 |
| Value range | 1 and 2. <ul><li>The value `1` indicates to use the old calculation logic. In this case, the value range of the `proxy_id` parameter is \[0, 255]. </li><li>The value `2` indicates to use the new calculation logic. In this case, the value range of the `proxy_id` parameter is \[0, 8191]. </li></ul> |
| Effective only after ODP restart | No |

For more information about the `proxy_id` parameter, see [proxy_id](1795.proxy-id.md).
