# rpc_service_mode

`rpc_service_mode` specifies whether to enable access to OBKV-Redis databases.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter was introduced in OceanBase Database Proxy (ODP) V4.3.2 BP1.</p>
</main>

|Attribute                       |Description                                                                                                                                                                                                                                                                                                                                    |
|--------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Parameter type                  |Integer                                                                                                                                                                                                                                                                                                                                        |
|Default value                   |3                                                                                                                                                                                                                                                                                                                                              |
|Value range                     |<ul><li><p><code>1</code>: indicates that only access to OBKV (OBKV-Table and OBKV-HBase) databases is supported. </p></li><li><p><code>2</code>: indicates that access to OBKV-Redis databases is supported. </p></li><li><p><code>3</code>: indicates that access to both OBKV databases and OBKV-Redis databases is supported.</p></li></ul>|
|Effective only after ODP restart|No                                                                                                                                                                                                                                                                                                                                             |
