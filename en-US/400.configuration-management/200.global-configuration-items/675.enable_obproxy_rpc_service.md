# enable_obproxy_rpc_service

`enable_obproxy_rpc_service` specifies whether to enable the RPC service port.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is introduced since ODP V4.3.0. </p>
</main>

| Attribute | Description |
|----------|---------|
| Parameter type | Boolean |
| Default value | True |
| Value range | <ul><li>`True`: specifies to enable the RPC service port. </li><li>`False`: specifies to disable the RPC service port. </li></ul> |
| Effective only after ODP restart | Yes |
