# rpc_ctx_expire_time

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is introduced in ODP V4.3.1.</p>
</main>

## Description

`rpc_ctx_expire_time` sets the expiration time for RPC login-related metadata. `0` means never expire. Entries not accessed within this interval are removed.

## Attributes

| Attribute | Description |
|----------|---------|
| Parameter type | Time |
| Default value | 1d |
| Value range | [0, +∞) |
| Effective only after ODP restart | No |

## Examples

Run the following command to set expiration to 2 days:

```shell
obclient> alter proxyconfig set rpc_ctx_expire_time= 2d;
```
