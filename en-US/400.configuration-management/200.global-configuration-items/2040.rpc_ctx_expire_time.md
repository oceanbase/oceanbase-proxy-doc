# rpc_ctx_expire_time

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is available starting from OceanBase Database 4.3.1. </p>
</main>

## Description

`rpc_ctx_expire_time` specifies the expiration time of RPC login information. If the value is `0`, the information will never expire. If the RPC login information is not accessed within the specified time, it will be deleted.

## Attributes

| Attribute | Description |
|----------|---------|
| Parameter type | Time type |
| Default value | 1d |
| Value range | [0, +∞) |
| Effective only after ODP restart | No |

## Examples

Run the following command to set the expiration time of RPC login information to 2 days.

```shell
obclient> alter proxyconfig set rpc_ctx_expire_time= 2d;
```
