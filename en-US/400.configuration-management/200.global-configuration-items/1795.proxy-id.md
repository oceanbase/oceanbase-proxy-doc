# proxy_id

`proxy_id` specifies the ID of an OceanBase Database Proxy (ODP) to ensure that the client session IDs generated by different ODPs do not conflict with each other.

| Attribute | Description |
|----------|---------|
| Parameter type | Integer |
| Default value | 0 |
| Value range | <ul><li>When `client_session_id_version` is set to `2`, the value range is \[0, 8191]. </li><li>When `client_session_id_version` is set to `1`, the value range is \[0, 255]. </li></ul> |
| Effective only after ODP restart | No |

For more information about the `client_session_id_version` parameter, see [client_session_id_version](135.client-session-id-version.md).
