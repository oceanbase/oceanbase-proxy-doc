# rpc_request_retry_waiting_time

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is available starting from ODP 4.3.0. </p>
</main>

## Description

`rpc_request_retry_waiting_time` specifies the wait time for retrying an RPC request.

## Attributes

|  Attribute  | Description     |
|----------|---------|
| Parameter type | Time type      |
| Default value   | 1ms     |
| Value range | [0ms, 10s]  |
| Effective only after ODP restart | No  |

## Examples

Run the following command to set the wait time for retrying an RPC request to 2 ms.

```shell
obclient> alter proxyconfig set rpc_request_retry_waiting_time= 2ms;
```
