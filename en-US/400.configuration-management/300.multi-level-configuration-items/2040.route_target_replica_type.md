# route_target_replica_type

`route_target_replica_type` specifies the replica type for routing weak-consistency read requests. This parameter takes effect only when `proxy_route_policy` is set to a value starting with `TARGET_REPLICA_TYPE_`.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is introduced in OceanBase Database Proxy (ODP) V4.3.2. </p>
</main>

|  Attribute    | Description     |
|----------|---------|
| Parameter type | String |
| Default value | Full;Readonly |
| Value range | <ul><li>`Full`: Read requests are routed only to followers.</li><li>`Readonly`: Read requests are routed only to read-only replicas.</li><li>`ColumnStore`: Read requests are routed only to columnstore replicas.</li><li>`Full;Readonly`: Read requests are routed to followers and read-only replicas.</li></ul><main id="notice" type='explain'><h4>Note</h4><p>If <code>proxy_route_policy</code> is set to a value starting with <code>TARGET_REPLICA_TYPE_</code> and <code>route_target_replica_type</code> is set to <code>ColumnStore</code>, read requests are routed only to columnstore replicas instead of the leader.</p></main> |
| Effective upon ODP restart | No |
