# init_sql

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is available starting from OceanBase Database 4.2.1. </p>
</main>

## Description

`init_sql` specifies the initialization SQL statements to be sent to the OceanBase cluster after ODP successfully connects to the cluster.

## Attributes

|  Attribute    | Description     |
|----------|---------|
| Parameter type | String      |
| Default value   | N/A     |
| Value range | N/A   |
| Effective only after ODP restart | No  |

## Examples

Run the following command to set ODP to initialize `_show_ddl_in_compat_mode` to `1` after it successfully connects to the OceanBase cluster.

```shell
obclient> ALTER proxyconfig SET init_sql='set _show_ddl_in_compat_mode = 1;';
```
