# enable_rpc_throttle

`enable_rpc_throttle` specifies whether to perform throttling based on the memory usage of remote procedure call (RPC) requests.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter is introduced in OceanBase Database Proxy (ODP) V4.3.2. </p>
</main>

|  Attribute    | Description     |
|----------|---------|
| Parameter type | Boolean |
| Default value | False |
| Value range | <ul><li>`True`: specifies to enable throttling.</li><li>`False`: specifies to disable throttling.</li></ul>  |
| Effective upon ODP restart | No |

## Examples

```shell
obclient> alter proxyconfig set enable_rpc_throttle=true;
```
