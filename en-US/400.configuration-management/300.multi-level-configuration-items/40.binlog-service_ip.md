# binlog_service_ip

`binlog_service_ip` specifies the address list of the binlog service cluster. The value can be one or more IP addresses or domain names. If you specify multiple IP addresses or domain names, separate them with semicolons (`;`), for example, `domain name 1:port number 1;IP address 2:port number 2;domain name 3:port number 3;IP address 4:port number 4`. The addresses are listed in descending order of priority. In other words, the first address is preferentially used.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter supports configuring multiple IPs or domains starting from ODP V4.3.1. </p>
</main>
