# obproxy_read_consistency

`obproxy_read_consistency` specifies the read consistency level of SQL requests.

|  Attribute    | Description     |
|----------|---------|
| Parameter type | Integer |
| Default value   | 0     |
| Value range | <ul><li>`0`: strong-consistency read. </li><li>`1`: weak-consistency read.</li></ul>  |
| Effective upon ODP restart | No |
