# proxy_route_policy

`proxy_route_policy` specifies the routing strategy for weak-consistency read requests in OceanBase Database Proxy (ODP), which defines the backend server to which client requests are routed for processing.

|  Attribute    | Description     |
|----------|---------|
| Parameter type | String |
| Default value | '', which indicates an empty string     |
| Value range | <ul><li>Empty string: The default routing strategy (`MERGE_IDC_ORDER`) of ODP is used. In this strategy, weak-consistency read requests can be routed to followers and read-only replicas. </li><li><code>FOLLOWER_FIRST</code>: Read requests are preferentially routed to followers. If all the followers are unavailable, the requests are routed to the leader. </li><li><code>FOLLOWER_ONLY</code>: Read requests are routed only to followers. If all the followers are unavailable, the connection to the client is terminated. </li><li><code>UNMERGE_FOLLOWER_FIRST</code>: Read requests are preferentially routed to a follower of which the cluster is not in a major compaction. </li></ul> |
| Effective upon ODP restart | No |
