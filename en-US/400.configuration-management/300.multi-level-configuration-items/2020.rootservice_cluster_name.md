# rootservice_cluster_name

`rootservice_cluster_name` specifies different attributes for different login methods.

* If you log in by using a service name, this parameter specifies the default standby cluster in read/write splitting mode.

* If you log in without using a service name, this parameter specifies the default cluster name of `rootservice_list` or a cloud user.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>This parameter was updated in OceanBase Database Proxy (ODP) V4.3.3 to distinguish between logins with a service name and those without a service name. If you log in by using a service name, this parameter specifies the default standby cluster in read/write splitting mode.</p>
</main>

|Attribute                       |Description|
|--------------------------------|-----------|
|Parameter type                  |String     |
|Default value                   |undefined  |
|Value range                     |N/A        |
|Effective only after ODP restart|Yes        |
