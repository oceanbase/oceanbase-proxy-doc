# obproxy_slow.log

obproxy_slow.log records logs for slow SQL queries, which refer to queries whose execution time is greater than the threshold (default value: 500 ms) specified by the `slow_query_time_threshold` parameter.

* Log format

   ```bash
   Log printing time,Logical tenant name,TraceId,RpcId,Logical database name,Physical database information (cluster:tenant:database),Database type (OB/RDS),Logical table name,Physical table name,SQL command,SQL type (CRUD),Execution result (success/failed),Error code (empty for success),SQL statement,Total execution time (μs),ODP processing time,Connection establishment time,OBServer node execution time,Current thread name,Ignorable fields
   ```

   where

  * The `SQL command` can be `COM_QUERY` or `COM_STMT_PREPARE`.

  * The `total execution time` includes the internal SQL execution time.

  * The `current thread name` indicates the internal thread ID in ODP.

* Log example

   ```bash
   2022-07-11 14:32:51.758270,undefined,,,,obcluster:sys:test,OB_MYSQL,,,COM_QUERY,SELECT,success,,select sleep(3),3041116us,409us,0us,3039883us,Y0-7F4B1CEA13A0,,,,0,11.xxx.xxx.53:33041
   ```
