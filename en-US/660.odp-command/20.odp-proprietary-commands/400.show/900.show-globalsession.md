# SHOW GLOBALSESSION

## Description

This statement is used to display session information in the session connection pool.

## Privilege requirements

The command can be executed only by the root@sys user and the root@proxysys user. The root@sys user can view all sessions of all tenants in the current cluster. The root@proxysys user can view all sessions of all clusters and all tenants.

## Syntax

```sql
SHOW GLOBALSESSION [ATTRIBUTE [all | 'db_key']]
```

## Parameter description

| Parameter | Description |
|-------|------|
| SHOW GLOBALSESSION | Displays statistics about the global session connection pool. |
| ATTRIBUTE | Optional. If you set this parameter, the command displays detailed information about sessions in the global session connection pool.  |
| [all \| 'db_key']  | Optional. You can set this parameter to `all` or specify a tenant. <ul><li><code>all</code>: displays information about all sessions in the global session connection pool. </li><li><code>db_key</code>: specifies a tenant in the format of <code>cluster name:tenant name</code>. If you set this parameter, the command displays information about the specified tenant. </li></ul> |

## Examples

* View statistics about the global session cache.

  ```sql
  SHOW GLOBALSESSION;
  ```

  The output shows that two sessions are cached for the `test` tenant.

  ```shell
  +-----------------+------------+---------------+
  | dbkey_name      | idle_count | idle_timeout  |
  +-----------------+------------+---------------+
  | obcluster:sys   |          0 | 1800000000000 |
  | obcluster:test  |          2 | 1800000000000 |
  +-----------------+------------+---------------+
  ```

  ```sql
  SHOW GLOBALSESSION ATTRIBUTE 'obcluster:test'\G
  ```

### Field description

The following table describes the fields in the output of the `SHOW GLOBALSESSION` command.

|       Field        |                    Description                     |
| ----------------- | ------------------------------------------- |
| dbkey_name   | The tenant to which the session belongs, in the format of `Cluster name: Tenant name`.   |
| idle_count  | The number of sessions in the tenant.   |
| idle_timeout   | The maximum time a session can remain in the connection pool before it is closed. The unit is nanoseconds. The retention period is controlled by the [session_pool_idle_timeout](../../../400.configuration-management/200.global-configuration-items/2200.session_pool_idle_timeout.md) parameter.  |

The following table describes the fields in the output of the `SHOW GLOBALSESSION ATTRIBUTE` command.

|       Field        |                    Description                     |
| ----------------- | ------------------------------------------- |
| dbkey_name        | The tenant to which the session belongs, in the format of `Cluster name: Tenant name`.                            |
| auth_user         | The user used to connect to the session, in the format of `Username@Tenant name#Cluster name`.                       |
| server_ip         | The IP address of the OBServer node corresponding to the session.              |
| local_ip          | The IP address of the ODP corresponding to the session.               |
| session_state     | The session state. Only `KEEP_ALIVE_GLOBAL_SHARED` is supported. |
| server_session_id | The unique ID of the session identified by OceanBase Database.            |
| ss_id             | The unique ID of the session identified by the ODP.             |
| create_time       | The time when the session was created.                              |
| last_release_time | The time when the session was last placed into the connection pool.                |
| timeout_time      | The expiration time of the session. After the session expires, it will be removed from the connection pool.                      |
