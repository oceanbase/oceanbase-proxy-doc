# ALTER

## Purpose

You can use this statement to change the value of a specified parameter of OceanBase Database Proxy (ODP).

<main id="notice" type='notice'>
  <h4>Notice</h4>
  <p>The <code>ALTER PROXYCONFIG</code> statement can modify only global parameters. Multi-level parameters must be modified by the <code>REPLACE INTO</code> statement. For more information, see the <b>Modify parameters</b> section in the <a href="../../400.configuration-management/100.get-and-modify-configuration.md">View and modify parameters</a> topic. </p>
</main>

## Syntax

```sql
ALTER PROXYCONFIG SET key=value;
```

The syntax is described as follows:

* When you update the value of a parameter, if the parameter cannot be found or the new value is invalid, the corresponding error code is returned.

* The value can be enclosed in single quotation marks (`'value'`) or double quotation marks (`"value"`).

* In ODP, parameters can be stored both in the `ob_all_proxy_config` table and on the local disk, or only on the local disk.

* If you update parameters stored on the local disk, the modifications are not synchronized to the `ob_all_proxy_config` table. If you update parameters stored in the `ob_all_proxy_config` table, the modifications are synchronized to the local disk to ensure consistency.

## Examples

1. Query the current value of the parameter to be modified.

   ```shell
   show proxyconfig like 'client_tcp_keepidle';
   ```

   The output is as follows:

   ```shell
   +---------------------+-------+-------------------------------------------------------------------------------------+-------------+---------------+
   | name                | value | info                                                                                | need_reboot | visible_level |
   +---------------------+-------+-------------------------------------------------------------------------------------+-------------+---------------+
   | client_tcp_keepidle | 5     | client tcp keepalive idle time, unit is second, 0 means use default value by kernel | false       | USER          |
   +---------------------+-------+-------------------------------------------------------------------------------------+-------------+---------------+
   ```

2. Change the value of the parameter.

   ```shell
   alter proxyconfig set client_tcp_keepidle=6;
   ```

3. Query the new value of the parameter.

   ```shell
   show proxyconfig like 'client_tcp_keepidle';
   ```

   The output is as follows:

   ```shell
   +---------------------+-------+-------------------------------------------------------------------------------------+-------------+---------------+
   | name                | value | info                                                                                | need_reboot | visible_level |
   +---------------------+-------+-------------------------------------------------------------------------------------+-------------+---------------+
   | client_tcp_keepidle | 6     | client tcp keepalive idle time, unit is second, 0 means use default value by kernel | false       | USER          |
   +---------------------+-------+-------------------------------------------------------------------------------------+-------------+---------------+
   ```
