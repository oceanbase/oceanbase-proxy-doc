# ping

## Purpose

You can use this command to verify whether OceanBase Database Proxy (ODP) is available. We recommend that you run this command as the super administrator `root@proxysys` of ODP. Other users may fail to log in to ODP if the ODP node breaks down.

## Syntax

```sql
ping proxy;
```

## Examples

```sql
ping proxy;
```

The output is as follows. In normal cases, this command always returns an OK message. If it returns an ERROR message, it means that ODP cannot work properly and must be manually restarted. Typical ERROR messages include `exceed memory limit` and `Got signal. Aborting!`.

```shell
Query OK, 0 rows affected
```
