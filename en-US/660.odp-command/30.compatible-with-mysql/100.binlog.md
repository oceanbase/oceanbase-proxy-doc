# BINLOG

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>Only the keyword syntax is supported. The functionality does not actually take effect. This statement returns an empty result set. </p>
</main>

## Purpose

`BINLOG` is an internal statement. 'str' is an encoded 64-bit string that can be parsed by the server.

## Syntax

```sql
BINLOG 'str';
```
