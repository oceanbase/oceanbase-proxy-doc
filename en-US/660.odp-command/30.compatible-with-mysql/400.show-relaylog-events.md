# SHOW RELAYLOG EVENTS

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>Only the keyword syntax is supported. The functionality does not actually take effect. This statement returns an empty result set. </p>
</main>

## Purpose

You can use this statement to query the event information in the relay log of a replica. If you do not specify `log_name`, the first relay log is queried by default.

## Syntax

```sql
SHOW RELAYLOG EVENTS
    [IN 'log_name']
    [FROM pos]
    [LIMIT [offset,] row_count]
    [channel_option]

channel_option:
    FOR CHANNEL channel
```
