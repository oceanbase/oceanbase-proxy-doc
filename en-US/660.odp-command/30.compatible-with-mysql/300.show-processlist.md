# SHOW PROCESSLIST

## Purpose

You can use this statement to query the process list of the current tenant.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <ul>
  <li>
  <p>Only the super administrator (<code>root@proxysys</code>) of OceanBase Database Proxy (ODP) can execute this statement to query the session information of all tenants in a cluster, and execute the <code>KILL</code> statement to terminate a session of any tenant in the cluster. </p>
  </li>
  <li>
  <p>A user in the sys tenant of an OceanBase cluster can execute this statement to query the session information of all tenants in the current cluster, and execute the <code>KILL</code> statement to terminate any session in the current tenant. </p>
  </li>
  <li>
  <p>Other normal users can perform operations only on sessions of the current user based on their privileges. By default, a normal user can only execute this statement to query the session information of the current user but cannot query the cluster information. </p>
  </li>
  </ul>
</main>

## Syntax

```sql
SHOW [FULL] PROCESSLIST;
```

## Parameters

| Parameter | Description |
|-------|--------|
| PROCESSLIST | The brief process list. Options: <ul><li><code>ID</code>: the ID of the process, namely, the client session ID of the current session. This ID is the unique identifier of the session in the client. </li><li><code>USER</code>: the user to which the session belongs. </li><li><code>HOST</code>: the IP address and port number of the client that initiates this session. If ODP is used to connect to the database, the IP address and port number of ODP are displayed here. </li><li><code>DB</code>: the name of the database accessed. </li><li><code>COMMAND</code>: the type of the command being executed, such as <code>Query</code> and <code>Sleep</code>. </li><li><code>TIME</code>: the execution time of the current command, in seconds. If the command is retried, the time is reset and recalculated. </li><li><code>STATE</code>: the status of the current session, such as <code>SLEEP</code> and <code>ACTIVE</code>. </li><li><code>INFO</code>: the command being executed. A maximum of 100 characters can be displayed and the exceeding part is discarded. </li></ul> |
| FULL PROCESSLIST | The complete process list, including the details of each process. Options: <ul><li><code>ID</code>: the ID of the process, namely, the client session ID of the current session. This ID is the unique identifier of the session in the client. </li><li><code>USER</code>: the user to which the session belongs. </li><li><code>TENANT</code>: the name of the tenant that is accessed in the session. </li><li><code>HOST</code>: the IP address and port number of the client that initiates this session. If ODP is used to connect to the database, the IP address and port number of ODP are displayed here. </li><li><code>DB</code>: the name of the database accessed. </li><li><code>COMMAND</code>: the type of the command being executed, such as <code>Query</code> and <code>Sleep</code>. </li><li><code>TIME</code>: the execution time of the current command, in seconds. If the command is retried, the time is reset and recalculated. </li><li><code>STATE</code>: the status of the current session, such as <code>SLEEP</code> and <code>ACTIVE</code>. </li><li><code>INFO</code>: the command being executed. </li><li><code>IP</code>: the IP address of the server to which the session belongs, which is the IP address of the OBServer node. </li><li><code>PORT</code>: the SQL port number of the server to which the session belongs, which is the SQL port number of the OBServer node. </li></ul> |

## Examples

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>For more information about this statement, see <a href='../../500.connection-management/400.server-session.md'>Server session</a>. </p>
</main>

* Use the `SHOW PROCESSLIST` statement
  
  ```shell
  obclient [SYS]> SHOW PROCESSLIST;
  ```

  The output is as follows:

  ```shell
  +------------+------+----------------------+------+---------+------+--------+------------------+
  | ID         | USER | HOST                 | DB   | COMMAND | TIME | STATE  | INFO             |
  +------------+------+----------------------+------+---------+------+--------+------------------+
  | 3221488068 | SYS  | 100.xx.xxx.xxx:18985 | SYS  | Sleep   |  298 | SLEEP  | NULL             |
  | 3221488078 | SYS  | 100.xx.xxx.xxx:32489 | SYS  | Query   |    0 | ACTIVE | SHOW PROCESSLIST |
  +------------+------+----------------------+------+---------+------+--------+------------------+
  ```

* Use the `SHOW FULL PROCESSLIST` statement
  
  ```shell
  obclient [SYS]> SHOW FULL PROCESSLIST;
  ```

  The output is as follows:

  ```shell
  +------------+------+-----------+----------------------+------+---------+------+--------+-----------------------+----------------+------+
  | ID         | USER | TENANT    | HOST                 | DB   | COMMAND | TIME | STATE  | INFO                  | IP             | PORT |
  +------------+------+-----------+----------------------+------+---------+------+--------+-----------------------+----------------+------+
  | 3221488068 | SYS  | oracle001 | 100.xx.xxx.xxx:18985 | SYS  | Sleep   |  548 | SLEEP  | NULL                  | 172.xx.xxx.xxx | 2881 |
  | 3221488078 | SYS  | oracle001 | 100.xx.xxx.xxx:32489 | SYS  | Query   |    0 | ACTIVE | SHOW FULL PROCESSLIST | 172.xx.xxx.xxx | 2881 |
  +------------+------+-----------+----------------------+------+---------+------+--------+-----------------------+----------------+------+
  ```
