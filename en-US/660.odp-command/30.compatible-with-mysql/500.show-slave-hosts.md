# SHOW SLAVE HOSTS

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>Only the keyword syntax is supported. The functionality does not actually take effect. This statement returns an empty result set. </p>
</main>

## Purpose

You can use this statement to list the replicas currently registered with the source.

## Syntax

```sql
SHOW SLAVE HOSTS;
```
