# ODP Community Edition V4.2.3

## V4.2.3

### Version information

* Release date: March 07, 2024

* Version: V4.2.3

* RPM version: obproxy-ce-4.2.3.0-3

### Overview

* The routing diagnostics feature is supported for routed statements. For more information, see [Overview](../../../600.data-routing/400.intra-tenant-routing/100.overview-of-routing.md).

* The connection diagnostics feature is supported. For more information, see [Connection diagnostics](../../../900.o-m-guide/500.connection-diagnosis.md).

* The Transport Layer Security (TLS) protocol version can be specified for a Secure Sockets Layer (SSL) connection to the database. Only TLS 1.2 and TLS 1.3 are supported.

* Binlog service address change is supported.

* Proxy Protocol version 2 (PPv2) is supported for Amazon Web Services (AWS).

### Bug fixes

* Fixed the issue where garbled characters are returned when OceanBase Command-Line Client (OBClient) uses the GBK character set.

* Fixed the issue that no error is returned when the feature for specifying the IP address is abnormal and port disconnection occurs.

* Fixed the issue where the connection to the binlog service fails occasionally after the high availability feature is enabled for ODP.

* Fixed the issue where ODP exits due to a prepared statement (PS) memory leak.

* Fixed the issue where disconnection occurs due to expired cluster information in a binlog request scenario.

* Fixed the issue where the process exits because the memory of ODP is used up due to a memory leak in the connection diagnostics feature.
