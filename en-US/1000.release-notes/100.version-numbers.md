# Versioning rules

Different versions of ODP may have significant differences in features and functionality. Therefore, you need to identify the ODP version that you need to obtain accurate documentation information.

The version of ODP is represented as V.x.y.z.f, where:

* x indicates the major version. This version usually involves architectural upgrades or the release of major new features.

* y indicates the planned iterative version. This version is part of the normal iteration plan and includes important feature updates and improvements.

* z indicates the release update version. This version contains minor feature updates and fixes for known issues.

* f indicates the patch upgrade version. The fourth digit is used when the version number needs to be incremented due to feature updates or bug fixes.

## View the version

After ODP is installed, you can use the following three methods to determine the ODP version:

1. The directory of a new version of ODP contains the version number. For example, the directory name obproxy-4.0.0 indicates that the ODP version is 4.0.0.

2. In the home directory of ODP, execute `./bin/obproxy -V` to view the ODP version. For example, the output is V3.2.3.

   ```shell
   [admin@test obproxy]# ./bin/obproxy -V
   ./bin/obproxy -V
   obproxy (OceanBase 3.2.3 2)
   REVISION: 6-local-99faebfc7130b70ad0f56330a28cab6a32ec9a33
   BUILD_TIME: Mar 30 2022 01:53:08
   ```

3. Log in to ODP as root@proxysys and execute `show proxyinfo binary` to view the ODP version. For example, the output is V4.0.0.

   ```sql
   MySQL [(none)]> show proxyinfo binary\G
   *************************** 1. row ***************************
   name: binary info
   info: ObProxy-OceanBase 4.0.0-20221103165243.el7
   version:RELEASE_7U
   MD5:
   REVISION:20221103165243-7c7e5821009b2d3924d1bc7a8165edf7384f6ed3
   BUILD_TIME:Nov  3 2022 16:57:16
   ```
